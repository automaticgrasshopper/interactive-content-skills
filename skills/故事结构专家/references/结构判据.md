# 结构判据（题材 + 故事 + 节奏，与《规则书》同源）

> 本文是《互动影视游戏设计规则书》第一~四部分的操作层浓缩，专供「出结构骨架」用。
> 符号：T=主线时长(分)；E=总结局数(三种之和)；P=(V,A,D)∈[−1,1]³=情绪坐标；落差=一段内 max−min；翻盘拍=D 由−→+；∝T=按 T/60 缩放；区间含两端。

## 0 全局

- 唯一自由变量：时长 T，基准 60 分，数量 ∝T。时长：用户指定 > 推荐，但受自洽检验约束。
- **输入自洽检验（第0步开头强制）**：容量公式＝主线骨架≥15分 + 每条完整情感弧光≈20分 + 每名仅露脸角色≈5分。用户给定时长 < 所需 → 判自相矛盾：真实意图＝内容承诺（角色都在、弧光完整）> 时长数字，上调时长到最小值并重定引擎；用户明确锁死时长 → 反向裁内容（减角色/减弧光，只写透2条）。裁决写进 consistency 与日志第0步。
- E＝三种结局之和：末段主结局 + 中间大结局(0–1) + 小结局/死路，全计入。先定主结局、再按余量铺小结局。"小结局"只指死路。

## 1 题材（先于故事）

- 视角：纯情感/乙女/美女陪伴→POV；纯故事→三视角；两者都重→按题材权衡。
- 必须提炼系统规则（防品类漂移）；必须有金手指且限定使用规则+场景。**金手指不限异能**＝"主角相对普通人独占的那点优势"：历史权谋·谍战中智力/谋略、乙女纯爱中主角魅力/共情力本身都算。
- 题材想象空间＝分阶段幻想契约：终极目标+中间阶段幻想；每阶段配一个强敌+一个可克服难关；事业维度承诺"正确游玩必达成"（悬念留情感维度）。
- **热门题材池**（推荐/融合优先取，非封闭）：男频＝历史模拟器/无限流/系统文/悬疑恐怖/盗墓冒险/末日生存/修仙炼丹/游戏竞技；女频＝宫斗宅斗/综艺想象/年代发家/萌宝萌娃/穿书逆袭/纯爱百合。
- 题材画像五项：核心幻想/阶段幻想清单/天然强敌/可克服难关/核心爽点。不达标→类型融合：①诊断缺口②按缺口选供能类型（缺强敌/规则→悬疑推理规则怪谈；缺生死代价→时间循环生存惊悚；缺幻想尺度→异能超自然异世界）③底色＝用户点名类型必兑现，融入类型只做惊喜，做成开场后反差催化剂④重验画像+logline。优先级：底色 > 供能。

## 2 故事

- 三维度：情感/事业/情绪（情绪为前两者因变量）。权重由题材定：恋爱重情感，非恋爱重事业。
- 认同开关三硬规则：①负面拍可剥离②爽点可认领且玩家选择促成③每撑开一个幻想空间登记一条"观众已知/主角未知"风险（反讽账）。
- PAD：取向=P目标−P当前；反差=P现实−P目标，V 或 D 反号＝强反差＝下段催化剂；强戏⟺拐点且|Δ|大。
- 结果硬规则：①情感维度含成/败两种可能②成功来自过程连锁反应非名义事件③铺陈→反差→催化剂④首个矛盾禁套路桥段（街头挑衅/电瓶车撞人），须由连锁反应+反差生成。
- **反俗套硬机制**（日志第0步展示）：①核心装置列3候选，弃第一直觉（训练集最高频）；系统面板/系统宕机/穿越即无敌/许愿代价类默认禁用②每次反转写连锁链（A→B→C 至少两环），禁外部事故反转（撞车/坠楼）③爽点登记 payoffs：D 负翻正 + 玩家抉择促成 + 一条反讽风险；全篇≥1，无翻盘拍＝不合格。
- 异性角色（恋爱+题材）：约1h体量2–3名（含1功能性，写透2名）；禁开场同屏多异性；依次登场每人讲透，后设福利汇总节点。选择后必须有后续爆发。
- logline：一句内含 期待/反转/钩子/情绪 四要素。
- **力度谱**（v1，∀时长同比例，强度取落差非绝对值）：开场 V∈[−.6,−.35]∧D≤−.5（V>−.3=压制不足）｜首释放 落差≥.7∧V≥+.4｜中段深压 V≤−.6∧相对前峰落差≥1.0∧轴反号｜高潮 V≥+.8∧相对谷底落差≥1.4∧D:−→+｜收尾 V∈[+.2,+.5]。禁：①连续2拍|ΔV|<.15（平戏）②两释放拍(V>+.4)间须有 V≤−.2 回落（防贬值）。
- **单点情节题材透镜（平情节禁令）**：每个关键情节四步——①落地一件具体的事②过题材透镜换反差物（反差物必须题材独有，换个题材就不成立；融合题材反差物取自供能类型。例：包子坏了→恐怖＝馅里疑似人肉见指甲；修仙＝一颗金丹；修仙奇幻＝金丹点石成金）③收口在题材逻辑内升级、禁常识收口（"老板补钱"禁作落点；恐怖收口"多给个包子：晚上十二点吃效果更好"＝双义钩子合格）④钩子＝下段催化剂口子，最强双义钩子。平情节（事件+普通人反应+常识收口）只许当铺陈，禁作节点落点。质检三问：反差物题材独有？收口升级非常识？钩子留口子？

## 3 节奏

- **引擎分档**：T≤10 极简结局树（1–2抉择,2–3结局）；10<T≤30 结局树（2–3抉择,3–4结局）；30–45 过渡＝完整七拍标准章；45分–2.5h 多章情绪弧；≥3h 长篇嵌套。10分钟硬线。七拍/四段分配/阶梯放置只对长片，短片一律结局树。
- **短片结局树五部件**：①装置先行（前约15%）②一次兑现+一记反转（唯一情绪引擎）③抉择树1–3几乎每个改结局④多结局2–4各有落点⑤前五分钟教学交互（通常＝第一抉择）。
- **长片七拍**：紧张开场→惊奇探索→好奇→进行探索→获得成就→章节高潮→震撼收尾；底线无聊点为零。每幕/章各是完整小情绪弧。
- 前五分钟强制交互点（长短片均适用）：教学+情绪代入+戏剧功能；通常不产生真分支；落在第一情节点高潮。
- 选择总量：长片∈[18,25]/60min（三类和,中位20,∝T）；短片1–3。
- 四段分配（仅长片，只数分支互动）：满载@60min 起5/承6/转5/合2(Σ18)；段上限=round(满载·T/60)；T>10每段≥1，全局≥2。
- **编织带**：互动间隔∈[2,4]集、连续无互动≤4；每互动2–4选项(荐2–3)有明确代价/后果差异；决策/情感类禁伪选项；首层分支≤4；深层"继续分支"汇合≥80%（死路不进分母）。护栏：死路均匀不扎堆∧同一互动不全死路。**空合流禁令（硬）**：同一 choice 任意两 next.to 不得相同；要合流须各选项先经一个不同 normal 节点再汇（✗ next[{to:1-3},{to:1-3}]；✓ next[{to:1-2-A},{to:1-2-B}] 再各自→1-3）。
- **结局分配软区间**（N=E，题材浮动取值）：N1→主1/中0/小0；N2→2/0/0；N3→2/0-1/0-1；N4→2/0-1/1-2；N5→2-3/0-1/2-3；N6→2-3/0-1/2-3；N7→3/0-1/3-4；N8→3/0-1/4-5；N9→3-4/0-1/4-6；N10→3-4/0-1/5-7。主结局下限2（N1或≤10min纯爱可1）、上限最多6；小结局＝余量，N≥5尽量≥主结局。节点总数≥E+1。放置(仅长片)：末段主结局全落"合"段、临近结尾连续数互动分批岔各1–2、禁单点炸开；中间大结局落起/承隐藏岔口；小结局均匀铺中段。冲突裁决：三种之和严格＝E 优先级最高。
- 时长推荐（仅未指定时）五因子：高唤醒负向→短；世界观重→长；群像多线→长；累积成长→长；信息密度高→适度拉长。锚点：恐怖/单案30–45；恋爱/职场/轻悬疑45–90；权谋/修仙/群像90–180+。

## 结局节点 kind 约定（给 JSON 用）

- `normal` 剧情节点（有 next）
- `choice` 抉择节点（next 每项 label 必填选项文字）
- `major` 算数正式结局，无 next，必加 sub：`sub:"end"`＝末段主结局 / `sub:"mid"`＝中间大结局(隐藏)
- `minor` 死路小结局，无 next
- id 用"集-序[-分支字母]"如 1-4、1-5-A

## 自检清单（第5步逐项过，有问题回步修正）

题材：视角匹配？系统规则已提炼？金手指已限定？每阶段强敌+难关？弱题材已融合？
故事：权重与题材一致？三维幻想成自发逻辑链？每空间登记反讽风险？负面可剥离/爽点可认领且玩家促成？成功来自连锁反应且含成败？logline 四要素？关键节点过题材透镜（反差物题材独有/收口升级非常识/钩子留口子）无平情节作落点？
节奏：引擎选对？（长片）七拍齐全无聊点为零？（短片）装置先行+兑现反转+抉择1–3结局2–4各有落点？前五分钟交互点落第一情节点高潮？选择总量达标？四段在区间内？无连续>4集无互动？每互动2–4选项无伪选项？无空合流？深层继续分支汇合≥80%？三种结局之和＝E？主结局落软区间且阶梯放置、小结局均匀铺不扎堆、同一互动不全死路？中间大结局≤1且必要？beats≥5且有D翻盘拍？
