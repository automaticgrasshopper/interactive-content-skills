# NXP · 规划故事板并生成剧集（自包含解耦版）

一句话：**在生成视频/图之前，先把"整集"当成导演作业解决完，再从整集里派生出可直接喂给 ref-to-video 的分镜组。**
本版本已解耦——所有关键规则都写在本文件内，`references/` 只放一份 JSON 输出契约（可选）。没有上游 skill 也能单独用。

## 目的

把「剧集描述 + 可选参考图/素材说明」转化为四样东西：

1. 完整的剧集级 16:9 电影化视觉策划板（整集节奏、一致性锁点、风险控制）。
2. 从相邻故事板帧派生的分镜组拆解（带剪辑节奏与生成风险控制）。
3. 每个分镜组的 ref-to-video 提示词。
4. 剧集视觉策划板本身的生成提示词（那张 16:9 网格制作板怎么画）。

章节名/结构/示例用中文。保留参考图里的人物身份、服装锚点、场景地理、风格限制；参考含糊时不要编造互相冲突的身份细节。

## 核心顺序规则（铁律，不许乱序）

1. **剧集故事板总览**：先解决整集——节奏、权力变化、情绪弧线、台词密度、空间、调度、总时长。
2. **故事板帧**：把整集拆成带时长/摄影/调度/台词/连续性的导演分镜帧。
3. **剪辑节奏层**：分组前先定每帧/每组的戏剧功能、信息密度、剪切触发点、表演起止、停顿预算、生成风险。
4. **分镜组**：只有在①②③都有之后，才把**相邻**故事板帧组合成组，每组必须能追溯到来源帧编号。
5. **Ref-to-video 提示词**：从做好的分镜组＋参考资产写视频提示词。不额外发明"先生成关键帧"的流程。

绝不在剧集故事板之前造分镜组；分镜组绝不与来源帧矛盾或跳过来源帧。

## 输入（有则用，无则按默认补并标注假设）

- `episode_description`（必需）：剧集故事素材、戏剧目标、动作推进、冲突、情绪转折。若只给了单个 `shot_description`，当成极短剧集描述处理。
- `character_references`（可选）：人物图/文字（服装、配饰、表情、姿态、身份限制）。
- `scene_references`（可选）：场景图/文字（地点、环境、陈设、布局、时间、天气）。
- `style_references`（可选）：美术方向、色彩、类型、摄影风格、目标平台、画幅。
- `story_context`（可选）：项目名、剧集名、前后集、连续性备注。
- `video_constraints`（可选）：模型限制、期望镜头数、机位数、负向限制、音频可用性、目标节奏、目标媒介（`interactive_cinematic_game` / `premium_tv_drama` / `short_drama` / `anime_layout` / `game_cutscene` / `commercial_film`）。

时长规则：**整集时长不固定 15 秒**，由故事本身（节拍数、台词、移动、场景变化、节奏）决定。分镜组则受视频模型上限约束；没给上限时默认每组最长 15 秒——整集可超，只有派生出的组要卡。

输入不完整不要卡住：仍输出可用板，把假设写进 `shared_creative_direction.assumptions`。

## 工作流

1. **抽固定锚点**：人物身份/年龄段/服装/发型/配饰/情绪基线；场景地理/出入口/关键道具/光源/天气/时代/质感；叙事节拍（铺垫→压力→转折→决定→揭示/悬念）；物理障碍与可行走路径（桌/墙/柜台/车/窗/栏杆/床/沙发/门都当真实实体，除非明说）。
2. **建剧集创意方向**：按故事需求估总时长并解释理由；规划场景地理、人物目标、权力变化、情绪节奏、台词、关键道具；给每帧派时长。
3. **设计剧集故事板**：人物与造型参考／场景与环境设计／俯视运动＋机位规划（标不可穿越物、可行走路径、出入口、视线、轴线）／故事板帧（人物+场景+调度+摄影+动作+台词+时长+连续性）／灯光情绪风格／情绪关键词块／音频与音调／摄影说明。
4. **加剪辑节奏层**：选目标媒介与节奏逻辑（短生成片段默认走互动影游/精品剧/短剧/动漫layout/游戏过场节奏，除非要求慢电影）；每帧/每组定单一戏剧功能、第一眼信息、表演起止、剪切触发点、允许停顿；**别把模型最大时长当填充**（只需 6–9 秒就用 6–9 秒）；标高风险模式（穿门槛/长距室内行走/多房间漂移/多个移动演员/大幅覆盖变化/关键人物可能消失）；关键可读文字线索优先戏内交付（台词/呼吸/反应/道具动作），不用扁平后期字卡（除非明确要求）。
5. **生成剧集视觉策划板提示词**：简洁 16:9 网格制作板；默认 1080P，稳不住降 720P；板块标签清晰；专业连贯电影化可读。
6. **派生分镜组**：只用相邻帧；按连续价值分组（运动路径/对话交换/物件因果/情绪节拍/视线关系）；遇时长超限/地点变/轴线重置/穿门槛/情绪目标变就拆；模型易漂移处（门到室内转场/长行走/"过肩再跟拍"/必要角色可能消失）拆或简化；每组含人物+场景+来源帧范围+总时长+故事板帧+连续价值+ref-to-video 提示词。
7. **返回前跑质量检查**（见末尾）。

## 必需输出（除非只要 JSON）

1. `剧集故事板` — 人物（身份锚点/服装连续性/当前目标）、场景（地理/不可穿越物/可行走路径/灯光/关键道具）、剧集节奏总览（总时长/节拍顺序/权力变化/情绪推进/时长理由）、故事板帧（时长/镜头感/景别/运动/调度/视线/动作/台词/情绪推进/连续性）。
2. `分镜故事板拆解` — 必须从①派生，标来源帧编号，不得加①里没有的新节拍。
3. `剪辑节奏` — 每组的目标媒介/戏剧功能/信息密度/剪辑节奏/剪切触发点/表演起止/停顿预算/建议生成时长/生成风险。
4. `Ref-to-Video 提示词列表` — 默认视频模型直接吃参考图/资产；除非明确要求，不要先生成关键帧。
5. `剧集视觉策划板提示词`。
6. `质量检查清单`。

完整 JSON 兼容 schema 与字段名见 `references/storyboard-output-contract.md`（可选，用于需要结构化产物时）。

## 视觉策划板提示词规则

必须指定：16:9 画幅；默认 1080P（1920×1080 或等效），失败可降 720P（1280×720）；简洁网格＋清晰板块标签；电影制作板/视觉规划表/导演前期指南的感觉；顶栏放共享创意指导+时长估算+类型+限制+色彩；人物模型表（多角度+服装配饰）；场景设计区+俯视运动/机位规划；**不可穿越物标签+可行走路径箭头（箭头绝不穿过桌/墙/窗/柜台/床/车/沙发/栏杆/关门）**；故事板帧带时长标签+简短摄影元数据；需要冲突/说服/揭示/情绪转折处加台词节拍；剪辑节奏备注（第一眼信息/剪切触发/停顿预算）；灯光情绪风格音频摄影说明块；专业电影化一致、高可读、不拥挤。

不要在图像帧内塞很小的正文；图内用短标签，详细文本放结构化输出。720P 降级时减少文字密度与缩略图数量、优先保布局可读。

## 质量检查（返回前逐条确认）

- 故事板尊重参考图、不违背固定视觉锚点。
- 图优先 1080P，失败可 720P 并说明降级原因。
- 整集时长由故事解释，不硬塞 15 秒。
- 分镜组在剧集故事板之后派生、标来源帧范围。
- 每组在视频模型时长限内，或解释例外。
- 每帧都有时长/人物/场景/调度/摄影/台词或有意沉默/连续性。
- 台词简洁、符合人物、能在该帧时长内自然表演。
- 人物移动尊重物理空间，不穿实体物（除非明确奇幻动作）。
- 对话覆盖体现权力关系/倾听/打断/隐瞒/揭示/情绪变化。
- 短片段不塞无关摄影变化；门口入场/室内行走/对话覆盖/坐姿反应易漂移时拆开。
- 每个生成单元的时长基于故事信息，不是直接取模型最大值。
- ref-to-video 提示词：含参考资产角色、连续性锚点、运动、台词/音频意图、负向限制；命名人物跨房间移动时含单实例人物锚点；门/门口/电梯/车门/闸门含明确首末帧或直接剪到结果态。
- 关键可读文字优先戏内交付（台词/反应/道具），必须视觉呈现时用生成前实体道具，不用扁平叠字（除非明确要求）。

## 失败处理

- 输入太少：仍出可用板，把缺口写进 `assumptions`，不卡住。
- 缺关键人物/场景锚点：按气质补合理默认并显式标注"这是假设，请确认"。
- 有人只要单镜：当成极短剧集处理，仍走"先整集后分镜组"的顺序（哪怕整集只有 1–2 帧）。
