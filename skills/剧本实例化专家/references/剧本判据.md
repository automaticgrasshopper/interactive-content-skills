# 剧本判据（分场剧本层，与《规则书》第七部分同源）

> 背景：当前 AI 视频生成对复杂运动与运镜表现差、镜头变形大，台词是传递信息最可靠的通道。所以剧本层总原则：**以传递本场信息与情感为目标，不以复杂运动和运镜为目标。**

## 一、角色分类（四类固定标签）

先判题材是否恋爱类（含 心动/乙女/美女like 标签或描述含恋爱/暗恋/告白等）：

- **恋爱类**：主角 / 男主 / 女主（异性情感核心，按性别向定，可多个）/ 配角 / NPC
- **非恋爱类**：主角 / 主配（核心配角，戏份重、推动主线）/ 配角 / NPC
- **NPC**：跨场出现但基本没戏、只需固定形象的功能角色（店员/辅导员/路人甲），必须列出并给 states 锁形象。
- 凡描述里写"情感一号/二号""主线情感"的角色，必须标男主/女主，**禁止降格标成配角**。
- 每个角色按此四类之一归类，不用其他词。

## 二、人物建置（台词提前立人）

- 未出场人物先用台词提及（"周老师说过……"）→ 该人物出场 → 主角以称呼确认（"周老师"）。
- 所有将出场人物，出场前先立起来，禁止无铺垫直接入画。
- 关系用戏剧（台词+情节）表现，不用旁白说明。

## 三、台词

- **口语化**：短句、有来有回、允许打断和省略，禁书面腔和说明文式对白。
- 默认中文。用户描述提及西幻或具体国家背景 → **必须用对应语种口语台词**（西方/英语→英文；日本→日文），并附中文对照。
- **台词比重高于动作比重**：信息与情感主要靠台词；动作只写必要的、画面内可稳定生成的。
- 对话必须符合人设，不同角色台词可**盲听分辨**（用词/语气/口头禅有别）。

## 四、镜头与调度（剧本层就约束，不留给分镜补救）

- 固定镜头为主（变形最小）；确需移动只用焦点移动（虚实焦切换）或微移。
- 动作描写只写必要、简单、画面内可稳定生成的动作；同场景内靠有效台词建构人物/关系/事件。
- **禁镜头外模糊调度**：谁在物理画面内就写谁，不写"望向镜头外的某人"、不暗示画面里没有的人。

## 五、人设状态

- 大纲阶段就梳理人物人设与场景（先于填台词）。
- 每个人物列出**全部状态**：从输入意图里分辨每个人物可能出现的所有形态与装束（例：西服/休闲装；真人/僵尸；动物/人形）。每状态单独描述外观要点，供画面生成锁一致性。

## 六、场景（分日夜）

- 场景必须分日景与夜景。同一空间若日景夜景都有戏，**分开写两条**（如"天台·日""天台·夜"），各描述光线氛围与视觉要点。
- 每场标 场景名 ＋ 日/夜 ＋ 内/外。

## 七、道具两级（都要固定外观，防跨场漂移）

- **核心道具**＝线索道具，承担至少一项功能：交代金手指 / 展示世界规则 / 与异性角色的信物 / 核心剧情反转扳机。
- **普通道具**＝戏剧性弱但跨场出现、形象需要固定（例：一次性消耗但跨场用了的钥匙）。
- **不入表**：只在单场出现、无跨场一致性需求、无戏剧功能的道具（一杯水、一张纸），剧情自动解决，不要罗列。
- 每件标：名称 / 级别（核心/普通）/ 固定外观 / 承担功能（核心必填四项之一）/ 出现场次。

## 八、输出物顺序

- **场景与人物总表（人物全状态卡＋场景日夜卡）＋道具表，先于分场剧本产出**——它们是角色图/场景图/道具图资产的直接输入。
- 之后逐节点填 script。

## 通读自检

- 全部 script 按顺序读一遍是否**顺畅如短篇**？符合自然逻辑与自然语言？
- 人物出场前都建置过了吗？台词都符合各自 voice、能盲听分辨吗？
- 场景日夜标全了？核心道具外观固定了？NPC 也列了状态卡了？
- 有没有写复杂运动/运镜、镜头外模糊调度？（有则改）
- **有没有擅自改动上游结构？**（不许——发现结构硬伤只提示，交回上游）
