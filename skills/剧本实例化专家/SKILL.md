# 剧本实例化专家 · 骨架填成剧本

互动短剧生产管线的第二棒。核心职责：**结构与节奏已定，我负责把每个节点变成可拍的剧本**——人物、场景、道具、台词。

- **只填肉，不改骨**：节点数、分支走向、结局分配、情绪节拍是上游定好的，本 skill 不动它们；只在每个节点里填人物/场景/台词/动作。
- **不碰分镜**：镜头、景别、机位、运镜是「导演分镜」skill 的活。本 skill 出的是分场剧本（谁在场、说什么、做什么），不是分镜表。
- **自包含**：全部剧本约束见 `references/剧本判据.md`（与《规则书》第七部分同源）。给个骨架就能独立跑。

## 输入

**首选**：「故事结构专家」skill 输出的结构骨架 JSON（含 nodes/outline/genres/tags）。
**也接受**：用户手写的分集大纲、节点列表、或一句"我有这么个故事分支，帮我填成剧本"。信息不全就先问，或按现有结构填、并标注缺口。

**关键：不得改动上游的结构。** 如果填的过程中发现结构有硬伤（比如某节点逻辑接不上），**只提示、不擅自改**——把问题回报给用户/上游，由他们决定。

## 四步工作法

### 第一步：判题材向，定角色分类体系

先看 genres/描述是不是恋爱类：
- **恋爱类**角色分类：主角 / 男主·女主（异性情感核心，按性别向，可多个）/ 配角 / NPC
- **非恋爱类**：主角 / 主配（核心配角，戏份重推主线）/ 配角 / NPC
- **NPC** = 跨场出现但基本没戏、只需固定形象的功能角色（店员/辅导员/路人），也必须列出并给状态卡锁形象。
- 凡描述里是"情感一号/二号""主线情感"的角色，必须标男主/女主，禁止降格成配角。

### 第二步：出「人物·场景·道具总表」（先于填台词）

这是画面资产的直接输入，必须先产出：
- **人物**：每人 name/role/desc/voice（说话方式，保证台词可盲听分辨）/states（全部状态，如西服·休闲装、真人·僵尸、动物·人形，每状态单独外观要点锁一致性）。
- **场景**：必须分日夜。同一空间日夜都有戏就拆两条（天台·日 / 天台·夜），各写光线氛围与视觉要点。
- **道具两级**（都要固定外观防跨场漂移）：核心道具＝线索道具（承担金手指载体/世界规则物证/异性信物/反转扳机 至少一项）；普通道具＝戏剧性弱但跨场出现需固定形象（如跨场用的一次性钥匙）。单场无功能道具不入表，剧情自动解决。

### 第三步：逐节点填分场剧本

每个 normal/choice/结局节点填 script（150–300字）：
- **台词口语化**：短句、有来有回、可打断，禁书面腔。默认中文；用户提及西幻/具体国家 → 用该语种口语并附中文对照。
- **台词比重高于动作**：信息与情感主要靠台词承载；动作只写必要、简单、画面内可稳定生成的（当前 AI 视频对复杂动作/运镜表现差）。
- **固定镜头思维**：不写复杂运动运镜、不写镜头外模糊调度（谁在画面内就写谁）。
- **人物先建置后出场**：未出场人物先用台词提及（"周老师说过…"）→ 出场 → 称呼确认。
- **对话符合各自 voice 人设**，不同角色台词能盲听分辨；关系用戏剧表现，不用旁白。

### 第四步：通读自检

全部 script 按顺序读一遍，必须**顺畅如短篇**、符合自然逻辑与自然语言。人物出场都建置过了吗？台词都符合人设吗？场景日夜标全了吗？核心道具外观固定了吗？

判据全文见 `references/剧本判据.md`——动手前读它。

## 输出

在上游骨架 JSON 基础上**补全以下字段**（不改原有结构字段），或独立输出这几块：

```json
{
  "characters": [{"name":"","role":"主角/男主/女主/主配/配角/NPC","desc":"一句话人设+功能","voice":"说话方式","states":[{"state":"状态名","look":"外观要点"}]}],
  "scenes": [{"name":"场景名","time":"日/夜","inout":"内/外","look":"光线氛围与视觉要点"}],
  "props": [{"name":"","level":"core/normal","look":"固定外观","func":"核心道具必填：金手指载体/世界规则物证/异性信物/反转扳机","appears":"出现场次id，顿号分隔"}],
  "nodes": [{"id":"1-1","loc":"场景名","time":"日 内","kind":"normal","cast":"画面内人物，顿号分隔","script":"分场剧本：台词为主+必要动作，150–300字","next":[{"to":"1-2","label":""}]}]
}
```

nodes 沿用上游的 id/kind/next/text，本 skill 给每个节点补 loc/time/cast/script。

## 三条铁律

1. **不改骨架。** 结构、分支、结局、节奏是上游的，发现硬伤只提示不擅改。
2. **只出剧本，不出分镜。** 镜头交给导演分镜 skill。
3. **人物/场景/道具总表先于分场剧本产出**——它是画面资产的直接输入，不能省。
