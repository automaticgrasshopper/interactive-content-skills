# 导演语法 · 把故事翻译成分镜

给擅长讲故事、但不擅长写分镜的人用。核心思路：**导演不是名字，是一套解决特定戏剧问题的视觉语法。** 用户描述一场戏，你负责诊断问题、挑语法、出分镜，并能一路走到可直接生成的分镜提示词。

## 四步工作法（分镜 → 分镜提示词）

### 第一步：先诊断"戏剧问题"，不是复述剧情

别急着分镜。先问自己一句：**这场戏要让观众产生什么？** 剧情是"发生了什么"，戏剧问题是"观众该被怎样对待"。同一段剧情，戏剧问题不同，拍法天差地别。

常见戏剧问题 → 速查（详细语法见 `references/directors.md`）：

| 这场戏想要的效果 | 首选导演语法 |
|---|---|
| 第一次发现真相 / 奇观 / 亲情唤醒 / 让观众认同 | 斯皮尔伯格 |
| 多线并行 / 倒计时 / 谜题 / 被巨大系统压迫 | 诺兰 |
| 谎言 / 审讯 / 调查 / 被监控 / 压抑控制 | 芬奇 |
| 悬念（观众知道危险、角色不知道）/ 窥视 / 延迟揭示 | 希区柯克 |
| 群像调度 / 天气即情绪 / 权力移动 / 道德冲突 | 黑泽明 |
| 家庭秩序 / 沉默 / 克制 / 静静旁观 | 小津安二郎 |
| 爱而不得 / 暧昧 / 错过 / 碎片化的亲密 | 王家卫 |
| 欲望 / 复仇 / 精密心理操控 / 对称的控制感 | 朴赞郁 |
| 仪式感 / 制度恐惧 / 冷峻空间 / 走向疯狂 | 库布里克 |
| 巨大尺度 / 神秘 / 负空间 / 命运压迫 | 维伦纽瓦 |

如果一场戏同时有两个问题（很常见），进第二步的"混搭"。

### 第二步：挑语法 —— 一主，至多一辅

**默认只用一个导演语法**，让画面有明确的性格。只有当一场戏真的扛着两个戏剧问题时，才加第二个作辅助。混搭的方式是**一个当骨架、一个当调味**，不是各拍一半。

推荐混搭（也可自己组）：

- **斯皮尔伯格 + 希区柯克** —— 情感发现里藏着危险（先给悬念信息差，再用反应镜头做温情揭示）
- **诺兰 + 芬奇** —— 倒计时调查、信息系统压迫（交叉剪辑的骨架，装进冷静对称的监控质感）
- **小津 + 王家卫** —— 安静家庭里说不出口的关系（小津的固定低机位打底，王家卫的前景遮挡与错位点情绪）
- **朴赞郁 + 芬奇** —— 精密心理操控（朴赞郁的对称调度，芬奇的冷静证据式特写）
- **黑泽明 + 库布里克** —— 群体权力冲突放进冷峻秩序（黑泽明的走位方向，库布里克的对称灭点空间）
- **维伦纽瓦 + 诺兰** —— 个人被巨大系统或命运困住（维伦纽瓦的负空间尺度，诺兰的交叉剪辑与倒计时）

混搭时明确写清：**谁是骨架（主导构图与运镜逻辑），谁是调味（只在关键拍子介入）。**

读 `references/directors.md` 拿到所选导演的具体镜头工具箱，再动手。

### 第三步：出分镜

把这场戏拆成几个"拍子"（beat），每个拍子给若干镜头。逐镜头填满字段，越具体越能直接拍、也越能喂给 AI 视频生成。

**先锚定相机（全场一次，别每镜换）**：给整场戏定一台相机机身 + 一组基准镜头，让整部片子的"底子"统一（这对 AI 视频的画面一致性很关键）。相机选型服务情绪——冷峻压抑偏数字大宽容度机身，温暖怀旧可偏胶片颗粒。

**每一镜必须给到的字段**：时长、构图、画面描述、景别、**焦段（mm）**、机位、运镜、情绪、动作、微表情、情绪变化、节奏、剪辑点、声音。

**焦段是性格，不只是远近**：
- 14–24mm 广角：尺度、压迫、空间扭曲、负空间；主体小、环境吞人（维伦纽瓦、诺兰的尺度）
- 35–50mm 标准：接近人眼，客观、日常、纪实（小津的正面直拍、芬奇的冷静）
- 85mm 中长：人物特写、压缩背景、把人从环境里隔离出来、亲密（王家卫、斯皮尔伯格的反应脸）
- 135mm+ 长焦：强压缩，群像像潮水（黑泽明），或偷窥/监控的距离感（希区柯克、芬奇）

选景别时顺手把焦段一起定了。

**运镜以固定镜头为主（重要）**：默认锁死机位，用固定画面讲故事。让画面里动的是**人物和环境**（雨落、闪电、怪兽穿过画框、水浪炸开），不是相机。运镜栏大多数时候就写"固定"。真要动，必须有压倒性理由，且轻、短、有落点；**绝不满场推摇，绝不一镜到底**。

**把"运动语法"翻成"固定语法"**——导演语法里凡是靠运镜实现的效果，优先换成固定镜头的等价做法：
- 缓慢推近 → **切**到更紧的固定景别（靠剪辑逼近，不靠推轨）
- 横移把两人连起来 → 一个固定的双人构图，让人物在框内走位
- 摇镜揭示 → **切**，或让被揭示的东西自己移进固定画框
- 跟拍 → 让人物在固定画框里穿过（进画 / 出画），或拆成几个固定机位接力

这样既保留导演的戏剧意图，又是用户要的固定镜头风格。

"这场戏在解决什么"（戏剧问题诊断）是你**动手前的思考**，用来定导演语法和镜头设计，但**不单列进输出**——保留顶部一行"导演语法"给用户看即可，其余落进表里。

**镜头数量的手感**：一场戏别贪多。情绪戏 3–6 个镜头往往就够，动作/信息量大的段落可以到 8–12。宁可每个镜头都有目的，也不要凑数。

### 第四步：出分镜提示词（接着分镜往下走）

把第三步的分镜表，逐镜转成可直接喂给 AI 视频生成的提示词。**一镜一条**，结构固定三段：

1. **开头（逐字写死，每条都必须有、且在最前）：**
   `不要出现BGM，不要出现字幕，保留音效。`
2. **风格与氛围**：全场统一的一句话，复用"全场相机"的质感 + 情绪基调（时代 / 天气 / 光线 / 色调 / 胶片颗粒）。每条都带上，保证整部片子调性一致。
3. **分镜内容**：把这一镜的表格字段串成一段通顺的自然语言画面——景别 + 焦段、**固定机位（明确写"固定机位、无运镜"）**、主体动作、环境动态（雨、闪电、碎片等让画面动起来的东西）、光线，以及要**保留的音效**（取自"声音"列，只要音效、不要配乐）。

把这一镜转成提示词后，逐条过下面的自检（必过）：

- ☑ 开头三句逐字不差，位置在最前。
- ☑ 全片无 BGM / 配乐、无字幕 / 画面文字（延续"画面里不出文字"的规矩）；音效保留。
- ☑ 运镜写"固定机位、无运镜"；若第三步某镜确有轻微动镜，就如实写清，但默认固定。
- ☑ 焦段和固定机位都带上，别丢。
- ☑ 只描述这一镜，不跨镜；不写剪辑点、情绪变化、微表情这些**分镜表内部信息**（它们是给人看的，不进生成提示词）。

## 分镜提示词模板

每一镜一条，严格照抄结构：

```
【镜头N】
不要出现BGM，不要出现字幕，保留音效。
风格与氛围：<全场统一的一句话质感 + 基调>
画面：<景别 + 焦段、固定机位无运镜、主体动作、环境动态、光线、保留的音效——一段通顺自然语言>
```

## 几条贯穿始终的原则

- **反应比事物更重要。** 观众的情绪来自人物的脸和身体，而不是那个东西本身。很多"发现真相"的镜头，先拍反应、再拍揭示，比反过来强得多（斯皮尔伯格、希区柯克都吃这套）。
- **机位就是态度。** 仰拍=让对象变大、变强；俯拍=让对象变小、被压；平视=平等/亲近；低机位固定=冷静旁观。选机位前先问"我想让观众怎么看这个人"。
- **固定镜头是默认，也是风格。** 用锁死的固定画框讲故事，让人物和环境在框里动。固定=克制、笃定、让观众自己看。只有理由极硬才动镜（比如缓拉把人推向孤立），且轻、短、有落点；坚决不满场推摇、不一镜到底。靠运镜实现的导演效果，优先用"切固定镜头"替代（见第三步的翻译表）。
- **相机和焦段也是叙事。** 全场锚定一台机身保持质感统一；焦段是情绪不是尺子——广角吞人、标准客观、长焦压缩与偷窥。选景别时顺手把焦段一起定。
- **留白和沉默是镜头语言。** 空镜、负空间、不给全貌、延迟揭示——不拍什么，和拍什么一样重要。
- **"这一镜服务了什么"是你的内部标尺，不写进表。** 每落一个镜头，心里都要能一句话答上来它在解决什么戏剧问题；答不上来，就删掉或改。这是你自我验证的标准，用户看到的只是干净的分镜表。
- **贴着用户的故事走。** 用户是编剧，故事和情绪是他的。你补的是"怎么拍"，不要改他的剧情走向；拿不准时按他写的字面来。

新手用户往往只会说"这段我想要 XX 感觉"。你的价值就是把那个模糊的"感觉"翻译成上面这张具体到可执行的表。
