# 分割视频

把用户指定的本地视频精确分割为连续、无遗漏的独立 MP4。默认每段 9 秒，最后不足 9 秒的片段也保留。

## 固定规则

- 保留源视频，不原地修改或删除。
- 输出名为 `<原文件名去扩展名>-001.mp4`、`-002.mp4`……；每个源视频都从 `001` 开始。
- 默认片段时长为 9 秒。用户明确指定其他时长时使用其值。
- 输入不足一个分段时长时仍输出 `-001.mp4`。
- 输出到用户指定的文件夹；未指定时先根据当前上下文确定安全且明显的输出位置，无法可靠判断时再询问。
- 默认不覆盖同名切片。发现冲突时停止并报告；只有用户明确允许覆盖时才使用 `--overwrite`。
- 写入工作区之外的目录前，按运行环境要求请求授权。

## 执行

先确认输入文件存在，并用 `ffprobe` 获取真实时长。然后运行：

```bash
python3 scripts/split_video.py <视频文件...> --output-dir <输出文件夹>
```

常用选项：

```bash
# 改为每 12 秒一段
python3 scripts/split_video.py input.mp4 --output-dir output --segment-seconds 12

# 用户明确允许覆盖已有同名切片
python3 scripts/split_video.py input.mp4 --output-dir output --overwrite
```

脚本依赖 PATH 中可用的 `ffmpeg` 和 `ffprobe`。它使用 H.264/AAC 重新编码，以避免只在关键帧处分割造成明显的时长偏差。不要为了追求速度擅自改成 `-c copy`，除非用户接受非精确切点。

## 完成检查

脚本成功后读取其汇总表，并确认：

- 片段数量为 `ceil(源时长 / 分段时长)`。
- 除末段外，各段与目标时长的偏差不超过一个视频帧或 0.05 秒（取较大者）。
- 末段大于 0 且不超过目标时长加同样容差。
- 所有片段可被 `ffprobe` 读取，文件名连续且没有缺号。

最终只需向用户说明输出文件夹、片段数量和每段实际时长；如果源视频保留不变，也明确说明。
