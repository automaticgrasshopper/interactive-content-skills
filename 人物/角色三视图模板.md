# 角色三视图模板（Character Turnaround / Model Sheet）

写实真人 AI 视频项目通用的人物设定表提示词。把人物特定信息抽成 `{ }` 占位符，**骨架语言固定不变**，所有角色复用同一版式，保证全片统一。

---

## 1. 通用模板（占位符版）

```
Photorealistic live-action film still style, wide 16:9 character reference sheet / character turnaround / model sheet for one single character: {CHARACTER IDENTITY — age, gender, ethnicity, build}, {HAIR — color, length, style}, wearing {OUTFIT}. {ART STYLE / MOOD}, believable practical realism, not cartoonish, consistent identity across all views.

Layout must be a clean production model sheet: left side shows the main character turnaround with three full-body views arranged from left to right: front view, side view, back view; full body, neutral standing pose, clear face, clear outfit, consistent identity, same outfit, same hairstyle, same proportions across all three views. Right upper area shows a larger detailed front face close-up with {FACE DETAILS}. Right lower area shows separate silent detail panels for: {HAIRSTYLE detail} and head area with no horns, {OUTFIT FABRIC}, {COLLAR / NECKLINE}, {LOWER GARMENT}, seam stitching and subtle texture, {ACCESSORIES}, {FOOTWEAR}, and character-specific {SIGNATURE DETAIL}. Use panel spacing and blank margins only. No text, no labels, no captions, no annotations, no arrows, no UI, no title, no logo, no watermark, no Front/Side/Back words in the image.
```

---

## 2. 占位符速查

| 占位符 | 填什么 | 示例 |
|---|---|---|
| `{CHARACTER IDENTITY}` | 年龄/性别/人种/体型 | `an ~29-year-old British white man, average height, slightly hunched` |
| `{HAIR}` | 发色+长度+发型 | `sandy beige, shoulder-length, straight` |
| `{OUTFIT}` | 主体服装 | `a plain muted skirt suit` |
| `{ART STYLE / MOOD}` | 全片统一画风（建议固定） | `grounded British black-comedy realism, low-saturation muted palette, 35mm grain` |
| `{FACE DETAILS}` | 皮肤/表情/眼神/碎发 | `sharp thin cheeks, cool composed expression, calm living eyes` |
| `{OUTFIT FABRIC}` | 面料 | `plain muted-tone suit fabric` |
| `{COLLAR / NECKLINE}` | 领口 | `tailored blazer lapel` / `polo collar` / `crew neck` |
| `{LOWER GARMENT}` | 下装/裙摆 | `skirt hem and drape` / `worn jeans` |
| `{ACCESSORIES}` | 配饰/道具 | `a slim handbag` / `minimal jewelry, bare ears` |
| `{FOOTWEAR}` | 鞋 | `plain low court shoes` / `scuffed trainers` |
| `{SIGNATURE DETAIL}` | 角色辨识符 | `a coffee-stained lanyard` / `a wedding ring` |

---

## 3. 固定骨架（不要改）

三视图布局（front / side / back）· 右上脸部特写 · 右下静默细节面板 · `no horns` · 末尾整串负向约束（no text … no Front/Side/Back words）。
这些保证所有角色的设定表版式一致。

---

## 4. ★ 全片统一画风规则

`{ART STYLE / MOOD}` **全片所有人物 + 所有场景用同一句**，否则会出现「不是一个世界」的跑偏。
本片基准风格：**low-saturation muted desaturated palette + naturalistic dim/underexposed lighting + 35mm film grain + gritty grounded bleak British realism**。
注意：灰调/颗粒只作用于**光线与氛围**，不要把人物服装的颜色也洗成灰。

---

## 5. 身份一致性（重要）

纯文生图、各自独立生成 **锁不住人脸**。要三态/多图是同一个人：

1. 选一张当**身份基准图**；
2. 其余状态用它做**图生图 / 参考图（identity reference）**，只用提示词改皮肤/眼睛/伤口/服装破损；
3. 文字层面把**脸部锁**逐字粘到每条提示词的身份句，把漂移压到最小。

**脸部锁示例（Sandra）：**
```
Face lock (keep byte-identical across all states): the same individual woman — long narrow oval face, high prominent cheekbones, a narrow tapering jaw to a slightly pointed chin, deep-set cool grey-blue eyes with a level calm gaze, straight slim nose with a fine bridge, thin lips with a soft cupid's bow, light straight sparse eyebrows, fair pale skin, sandy beige shoulder-length straight hair with a soft side part. Same bone structure and same proportions in every state; infection only changes skin, eyes and wounds, never the underlying face shape.
```
