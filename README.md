# 影视互动游戏 · 故事节奏 Lab (interactive-drama-lab)

> 影视互动游戏「故事节奏」核心资产：故事节奏验证 H5、设计规则书、导演分镜方法与配套 skill。

最后更新：2026-07-03

## 内容

| 路径 | 是什么 |
|---|---|
| `h5/影视互动游戏故事节奏验证.html` | 故事节奏验证 H5（含**执行卡**、代码）。浏览器直接打开。管结构+节奏+剧本。 |
| `h5/分镜工作台.html` | 分镜可视化 H5（第二个网页，V0.1）。只做“分集/一场戏 → 分镜表 + 分镜提示词”；两种输入（接第一个 H5 的剧本 JSON / 手填一场戏）。内嵌导演分镜执行卡，与 skill 同源。浏览器直接打开。 |
| `规则/互动影视游戏设计规则书.md` | 主设计规则书。 |
| `分镜/导演分镜故事版拓展能力_学习文档.md` | 导演分镜方法手册：故事 → 诊断戏剧问题 → 挑导演语法 → 出分镜表 → 出分镜提示词。 |
| `人物/角色三视图模板.md` | 角色三视图设定表（character turnaround / model sheet）生图规则：固定版式骨架 + 占位符，全片版式/画风/身份统一。 |
| `skill/故事结构专家/` | 【管线①源头】把题材/描述/时长/结局数 → 结构骨架（题材标签/大纲/分集节点与分支/情绪节拍/结局分配）。只出结构与节奏，不填台词/分镜。输出骨架 JSON → 可喂给剧本实例化专家。 |
| `skill/剧本实例化专家/` | 【管线②填肉】吃结构骨架 → 实例化为可拍剧本（人物全状态卡/场景日夜卡/道具两级表/逐节点分场剧本）。只填肉不改骨，不出分镜。 |
| `skill/导演分镜故事版拓展能力/` | 【管线③分镜】把一场戏翻译成逐镜头分镜＋可嗂 AI 视频的分镜提示词（导演视觉语法）。放进 `~/.claude/skills/` 即可用。 |
| `skill/角色三视图设定表生成能力/` | 【旁支·人物图】把人物设定翻成三视图生图提示词（固定版式锁脸防漂，多状态）。 |
| `skill/节奏题材校验专家/` | 【旁路·质检】对一份已生成的互动短剧只从题材/节奏两维度对照规则书质检，三档判定（硬伤退回/中度给建议/轻微放行），不阻塞其他 skill。

> **管线串联**：①故事结构 → ②剧本实例化 → ③导演分镜；每个 skill 都自包含、能独立跑，串联只是“上一个的输出恰好能当下一个的输入”，不互相依赖。H5 网页仍可一站式出完整剧本（给没 agent、只有浏览器的用户），skill 与 H5 同源并行。 |
