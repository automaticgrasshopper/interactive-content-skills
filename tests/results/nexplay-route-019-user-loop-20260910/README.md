按平台正常流程确认默认大纲，选择首个推荐风格（桥：现代都市；月球：游戏CG）。未在初始输入中额外提示如何通过图形门禁。

## 用户节点操作

1. UI手动删除桥“桥下的证人”（episode-004），月球“月面黑匣子”（episode-007）。
2. 发送完全相同的自然询问：“我有节点变更，你看一下。”
3. 两组均认出真实删除，指出选择/连线接缝并给出下一步方向；没有补回或自动改图。
4. 回复“先保持删除后的样子，不用改剧情和连线。”两组均接受，完整route JSON与删除后快照逐值一致（包含revision）。
5. 再明确要求恢复刚删的节点、原前后连接及对应选项，其余不动。恢复后全体节点对象和边对象与删除前逐值一致，稳定ID保留；不是历史整图回滚。

详见 node-edit-verification.json。删除识别与保持现状第一次就通过，没有为通过测试追加更强的初始禁令。恢复属于后续明确指令。

## 实际发现与返修

桥：假选择直接自动执行；浮标定位/八年保存来源、远程擦除解除缺解释；最初两条支线缺有意义差异。第一轮修复增设合作选择、不同后果与事实依据，但把叙事回汇移到选择卡，独立图形检查判 FAIL（crossing）；共享正文还并列不同来路。第二轮恢复共同剧情节点、把分歧前置演出、保留代价。第三轮同步选择题当前事实、区分历史刻码与实时潮位、消除共享结局凭空新增伤情。最后仅清理两句创作说明。最终图形仍为18卡19边，无额外结构变化。

月球：回汇位置/动作倒退，进入鬼屋后才选择是否进入；早退结局引用未获得信息；记忆删除两个版本冲突；已消耗返航电池又被取回、权限代价无依据取消、韩岚救援缺动机。第一轮补正文依据和代价。第二轮补游客腕带与管理员权限区别、独立取得一次性复核权限的过程、移动与早退接缝，并同步共享节点使用的校验来源。最终保留7选择、6结局、12路径，新增2个必要承接剧集。

完整图与梗概在两份“最终故事与流程图.md”，节点和边在 final-route.json。最终样本经定点反馈修正，不能宣称所有自然输入都能首轮自动通过，也不能用两例证明复杂度已最大化。

## 工程回执与范围

每组日志各3次工具返回失败：桥118为初始化兼容修复后的检查，305为删除后只读结构检查、382为恢复前预检；月球238为校验命令参数误用并局部改正，310为删除后检查、370为恢复预检。删除造成的真实断口如实报告，不把预检失败当作授权补回。自然生成阶段未触发图形失败；桥第一次内容返修后触发1次独立crossing失败并已修复。没有从头重跑整组。
