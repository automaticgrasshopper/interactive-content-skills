# 交付与版本关系

## 业务对象不变

字幕烧录不创建新的公开业务对象。对每个输入`分镜视频`：

- 保持原`video_id`不变；该 ID 继续供游戏拓扑、播放器和封面流程引用。
- 保持用户可见名称不变；不要追加“字幕版”“最终版”“v2”等前端名称。
- 顶层输出仍叫`分镜视频`，文件或 URL 指向最新验收通过的字幕烧录版本。
- 不新增`字幕视频`、`字幕成片`、`烧录视频`或其他顶层字段。

前端的一条`分镜视频`与存储层的多个媒体文件不是一回事。前端保持一项，存储层保留可追溯版本。

## 私有版本台账

在非 Canvas 的私有工作区维护每个`video_id`的版本关系，至少能够解析：

- 无字幕母版的稳定引用与版本。
- 本次字幕计划版本。
- 本次烧录媒体引用。
- 上一版烧录媒体引用。
- 路线适配版本存在时，`route_id`到烧录媒体的映射。
- 当前前端/游戏应使用的活动媒体版本。

具体字段名服从运行时 capability manifest 或系统适配器，不要求上游新增 Sheet 字段，也不把台账作为业务输出。

运行时支持不可变媒体版本或 rendition 时，把烧录文件注册为同一业务视频的新版本/rendition，并原子切换活动媒体。运行时不支持时，也必须在私有台账中保留母版和版本关系；对外仍返回原`video_id`与新文件/URL，禁止伪造新业务 ID。

## 修改与重烧录

用户修改字幕时：

1. 用`video_id`找到无字幕母版、当前母版版本和上一版私有字幕计划。
2. 只修改用户指定的字幕事件；未指定事件保持不变。
3. 始终从无字幕母版重新烧录，不从当前带字幕版本继续烧录。
4. 生成新的不可变烧录版本，验收通过后再切换活动媒体。
5. 失败时保留当前活动版本，不把半成品暴露给用户。

母版视频被上游重做或替换时，使旧字幕计划失效；重新做时长、音频、人物与安全区对齐。

## Canvas 可见性

默认不向 Canvas 写入任何字幕阶段文件。以下内容始终私有：

- 无字幕母版、空镜源文件和临时合片。
- 字幕计划、ASS、SRT、字体副本、音频或听写证据。
- 抽帧、接触表、安全区检查、质量报告和日志。
- 旧烧录版本、失败产物、版本台账和索引。

如果调用方明确规定 Canvas 是最终媒体展示面，只允许写入验收通过的最终`分镜视频`媒体；文件的展示名称必须沿用对应业务视频名称。不得创建过程目录、索引页或文件清单。

测试、调试或用户要求查看诊断时，优先返回简短诊断结论。只有用户明确要求取得某个过程文件时，才临时提供该指定文件；不要因此公开整个私有工作区。

## 完成交付

验收通过后的顺序：

1. 保存烧录媒体为独立版本。
2. 验证它关联原`video_id`与正确母版版本。
3. 切换同一`分镜视频`业务项的活动媒体引用。
4. 只返回顶层`分镜视频`及其状态和文件/URL。
5. 将内部状态记为`completed`并放行封面。

任一步失败都不切换活动媒体，不公开过程文件，并保持封面阻塞。
