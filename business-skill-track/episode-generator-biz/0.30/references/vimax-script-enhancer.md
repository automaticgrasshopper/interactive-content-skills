# ViMax Script Enhancer

本 reference 只在Screenwriter已输出完整草稿后使用。目标是把已经成立的剧情扩成清楚、可拍、能顺读的最终剧本，不改变冻结故事、拓扑、梗概、选择、结局或停止边界。

## 输入边界

只读取当前`screenplay-drafts/<episode-id>.md`、本 reference以及当前集停止边界。不得读取过程链、验收答案、冷读问题、旧增强稿、后续正文或其他路线。

## 增强任务

完整通读草稿后一次性重写全场：

1. 保留草稿中的事件顺序、行动结果、场景、人物、道具与结尾位置。
2. 把过度压缩的动作补成观众能连续看见的接触、阻力、反应和结果，不靠作者总结跳步。
3. 人物首次进入时，用现场动作、频道来源、自然报号、职务称呼或关系称呼说明其当下身份；已清楚的内容不重复登记。
4. 让问题、命令、请求、反驳和迟疑得到现场回应；保留称谓、对象、态度和关系指向，不把话轮压成信息骨架。
5. 台词使用直接可懂的现代汉语，允许危急口令简短，但相邻话轮必须接得上。
6. 结尾停在草稿已经建立的压力或判断上；不得提前完成停止边界列出的后续独占动作、核验、选择或结果。

不得新增角色、场景、道具、规则、证据来源或未来情节，不得把同一身份和风险在旁白与对白中反复解释，不得加入审稿标签、作者判断、主题金句或制作话术。

## 输出

把增强后的完整连续场景写入`enhanced-screenplays/<episode-id>.md`。只输出剧本正文。该文件是唯一正式正文候选；后续结构验收、场面展开复检和独立冷读只读它，不再生成第三版正文。
