# 拓扑双复检

正式拓扑完成确定性校验和路线记账后，当前任务必须对同一封闭材料包串行完成A、B两遍完整复检。两遍都只判不改，不读取生成过程中的评价、修改建议或预期答案；B遍从材料包重新判断，不复制A遍结论。

- A遍以故事投影和因果为观察重点：主线覆盖、决定裂缝、动作后果、持续差异、支线逐路重新扫描与汇合基础。
- B遍以路线和整体结构为观察重点：未结任务是否得到足够路线空间、四类结局兑现、戏剧单位完整性、节点必要性和是否受固定形状挤压。

观察重点不同不等于缩减检查范围。每遍都必须覆盖材料包中的全部固定检查，并给出包内逐字证据。返回合同：

```json
{
  "contract_version": "nextplay.topology-double-review.v2",
  "packet_sha256": "材料包规范化摘要",
  "review_pass": "A或B",
  "verdict": "PASS或FAIL",
  "checks": [{"check": "固定检查名", "passed": true, "explanation": "本遍判断", "evidence": [{"artifact": "包内文件名", "quote": "逐字证据"}]}],
  "issues": []
}
```

当前任务依次封存A、B回执。两遍均绑定当前材料包并PASS后才可继续；任一FAIL都返修最早错误材料，材料变化使两份回执同时失效。整个过程自动续跑，不创建其他任务，不询问用户是否继续。
