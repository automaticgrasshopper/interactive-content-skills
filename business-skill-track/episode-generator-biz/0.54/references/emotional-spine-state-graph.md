# 故事线、情绪运动与全图情绪脊

情绪不在完整故事之前预制内容，但完整故事冻结后，它与因果共同驱动拓扑。先从已发生事件提取主线情绪运动，再让每个真实动作沿不同情绪方向生长；正式拓扑和全体梗概冻结后，节点级情绪脊逐边证明这张图确实承载了这些运动。它不是装饰性曲线，而是进入逐集剧本前最强的全图门禁。

## 拓扑前情绪运动合同

`mainline-emotional-movement.json`使用`nextplay.mainline-emotional-movement.v2`，绑定当前`complete-story.json`和`mainline-decomposition.json`。`movements`中的每项严格包含：`movement_id`、`segment_ids`、`source_proof`、`phase`、`current`、`target`、`reality`、`pressure`、`desired_state`、`reality_shift`、`control_change`、`unresolved_task`、`catalyst`、`audience_known_risk`和`candidate_fissures`。

- 全部主线切片至少被一项运动覆盖；`source_proof`必须逐字来自所引切片。
- `phase`只描述该段在当前故事中的功能，可取`setup`、`development`、`reversal`或`resolution`；不要求四段齐全、固定顺序或固定数量。`current`、`target`、`reality`都写VAD坐标，目标与当前不能重合，现实与目标必须有可测反差。
- 多段主线至少发生一次显著现实转向。压力、欲望、现实变化、控制权变化、下一催化和观众已知风险必须指向同一条未结任务，不能只换坐标不换故事状态。
- `candidate_fissures`只记录人物在该压力下真实可能面对的行动问题，不写节点、边、结局类别或数量。
- 决定裂缝必须绑定一项或多项当前情绪运动，同时仍要独立满足事实层的可执行、互斥和后果差异；情绪意义不能制造事实层不存在的选项。
- 本文件通过`validate_mainline_emotional_movement.py`后才允许创建`decision-fissure-audit.json`。

## 路线判断

每个真实决定发生后，先演出各动作的即时后果，并登记每个动作的`emotional_direction`、人物必须承受的`emotional_cost`以及动作后的`unresolved_task_after`。同一选择的动作必须指向不同方向，不能只是同一后果的措辞变体。随后同时判断：

- 核心目标仍然有效、可达并被人物继续追求吗；
- 人物是否仍处在本故事主要承诺覆盖的行动范围内；
- 新的关系、资源、风险和控制权差异是否已演出；
- 当前因果与情绪任务是未结、可与其他路线共用，还是已经完成。

据此决定去向：

- `继续`：核心目标仍有效，且行动、阻力或情绪任务尚未完成。
- `带差异汇合`：路线重新面对同一个可执行问题，并有共同事实支撑；已经造成的关系、资源、风险与控制权差异继续保留。
- `小结局`：人物放弃核心目标、目标永久不可达，或人物转入不再承载本故事主要承诺的生活；局部因果和情绪已经结算。死亡只是其中一种。
- `失败结局`：人物始终留在核心故事内，把目标推进到主要验证，但最终失败。
- `主结局`：冻结完整故事原路线的自然终点。
- `期望结局`：另一条主要路线最充分兑现核心目标、题材幻想和观众主要期待。

初次生成四类结局各至少一个，期望结局与主结局必须是不同节点。小结局只要求至少一个，不按位置、裂缝数或比例配额；已有一个后不得为了补数继续制造早退叶子。自然出现多个时，必须具有不同的离场事实，不能都是“停止追查”的换皮。

VAD只解释情绪运动，不单独决定路线类型：

- `V`效价表示苦乐结果；`A`唤醒度表示平静或激活；`D`支配度表示受制或掌控。
- 小结局可以因主动离场而变得平静甚至愉快，不能因V上升误判为期望结局。
- 失败结局可能有关系收获，不能因局部V上升误判为成功。
- 期望结局通常具有核心目标兑现和可见的掌控度转变，但不能只靠坐标命名。

路线可以短于、等于或长于冻结主线。只要行动后留下的情绪任务仍有因果动力，就继续生长、再次决定或带差异汇合；不能以“已经走过主线位置”或“节点够了”为由提前结束。不得先决定汇合、死路或四类结局，再倒推情绪坐标为结构服务。

## 正式投影合同

`emotional-spine.json`使用`nextplay.emotional-spine.v3`。它在全体梗概冻结后生成，使每一个情绪判断都有正式节点文本的逐字证据：

```json
{
  "contract_version": "nextplay.emotional-spine.v3",
  "nodes": [
    {
      "episode_id": "episode-001",
      "movement_ids": ["movement-001"],
      "source_proof": "对应冻结梗概中的逐字证据",
      "valence": -0.2,
      "arousal": 0.5,
      "dominance": -0.3,
      "turn": true,
      "turn_reason": "当前已冻结事件为何形成真实情绪转向",
      "turn_proof": "对应冻结梗概中的逐字证据",
      "unresolved_task": "本节点结束后仍需面对的情绪任务",
      "settlement": "open、partial或resolved"
    }
  ]
}
```

- 节点集合与顺序必须等于正式拓扑；`source_proof`与`turn_proof`必须逐字来自该节点冻结梗概，`movement_ids`必须指向已验证的主线情绪运动。
- 三个坐标均在`[-1,1]`。每条边都要发生可测状态变化；显著变化必须由目标节点声明真实拐点。选择后的直接后继必须形成足够方向差，不能靠同一条情绪轨迹伪装分支。
- 每条入口到结局路线至少包含一次显著拐点。非结局节点不得提前写`resolved`；所有结局节点必须写`resolved`并说明结清了什么。
- 主结局、期望结局和失败结局的情绪落点必须彼此可区分；类别只解释最终结算，不指定它们位于哪一层。
- 情绪平缓本身不是错误；但连续节点既无新行动后果又无关系、风险、理解、控制权或未结任务变化时，必须回到故事图或拓扑修复，不能改坐标掩盖空节点。

验证顺序固定为：主线运动合同 → 决策裂缝方向 → 支线结局落点 → 拓扑与梗概冻结 → 全图逐边情绪脊。最后一关任何路线失败，都不得创建`planning-acceptance.json`或进入逐集剧本。
