# 字幕规则

## 内容

- 字幕对应实际视频中存在的对白、旁白或用户明确要求展示的说明文字。
- 台词字幕必须从当前实际视频原声提取逐句文字和时间，再核对写轨；不得先从剧本抽句再估时间。剧本仅校正专名及有原声证据的听写错误，不能替代转录。原声与剧本不同，按原声；视频未说的话不添加，剧本没写但实际说的话不遗漏。
- 世界观、人物介绍、章节说明和结局文字应与台词字幕区分，避免混成对白。人物首次登场介绍按 [文字画面规则](titles-and-posters.md) 处理：以本次选定范围的实际视频顺序找首次清晰且无世界观冲突的时段，已有对应介绍不重复。

## 原声来源与剪后对齐

在内部运行记录保留每条转录的真实媒体引用/版本、源起止时间、提取能力及核听证据，连同修改前视频和字幕留底。实际语音识别或视频理解能力必须接收真实视频/音频；只读剧本、分镜文字或Prompt不算完成提取。能力未能确认语音时标记待核对，不用剧本文字顶替。

每次听辨优先只传一个真实源视频，先不提供预期台词答案，再用剧本校对专名。批量输入被工具拼接、时长感知与真实文件不符、无法确认第二段起点时，该批次时间证据无效；改为逐源片段单独核听，禁止用“画面大约切换在某秒”的推断当独立源时间。明确区分源视频坐标与剪后时间线坐标；工具说“说全”不能替代真实剪后播放核验。

先按源片段提取，按真实 source_range 与 timeline_range 换算剪后显示区间；重排、拆片、裁剪后逐句核对实际保留声音，不能按原镜头编号累加建议时长。可使用已验证的同媒体版本转录，但须重新计算受影响区间并回听。自动剪辑须对照剪前清单与拟删功能判断，保留必要戏剧功能和完整的剩余话语；符合剪辑规则而完整删去的非关键对白不再作为成片字幕内容。发现误剪关键台词或留下半句时先报告并恢复已授权范围，不让字幕凭空显示被剪掉的声音；已有字幕是否调整仍遵循用户的处理选择。

## 时间与断句

- 字幕出现和消失应跟随实际视频原声或对应画面。优先使用可用的带时间戳语音识别，并核对句子开头和结尾；只有粗略时间段时标明尚未精确对齐，不按剧本行数、平均句长或整片比例猜时间。多段视频组装后，按源片段实际时长和裁剪范围换算偏移，不用建议时长代替实测。
- 按完整语义和自然停顿断句，不切断人名、固定短语或中英文对应关系。
- 删除、插入或重排视频后，仅在用户选择处理字幕时修改受影响事件；拒绝则保留轨道原样并说明风险，按[字幕询问](subtitle-interaction.md)执行。

渲染的对白只含实际台词正文，不带说话人标签、冒号、动作或舞台说明；说话人保留作内部核对。中文一般每行不超过18字、最多两行，双语中文可收紧至16字，按实际语义和语音调整；这些是阅读建议，不是据此猜时间。紧密接话直接切换，不人为加空白或淡入淡出。每条实际口语与字幕事件双向对账，分句/合句保留对应关系，不能漏句或重复。

## 句号清理与标点强制校验

对白／旁白timed_text、人物姓名／身份character_intro不保留句号，中文及其所有译文均适用。世界观／前情worldview及其译文不执行句号清理，允许保留句号；不得因本规则改动世界观文字。删除句首、句中和句尾用作句号的`。`、`.`、`．`，不是“通常省略”，对白、旁白及人物介绍的译文同样清理。用户要求保留原文时保留措辞与事实，仍执行本句号清理；不要以复制原文、翻译结果或已有轨道为理由跳过。

以下清理和校验仅适用于对白／旁白及人物介绍。句中两个完整短句去掉句号后若不便阅读，可按实际语义与原声拆成显示行／字幕事件，或用正常分句逗号连接，不改变说话内容和语音时间。每条显示字幕末尾省略普通逗号；问号、感叹号正常保留。省略号、破折号按真实语气保留，小数点及词语内部符号不当作句号；不能把普通句号伪装成省略号来规避清理。

例如：`别急。我给你留着灯。` → `别急，我给你留着灯`；英文对白`Wait for me.` → `Wait for me`；世界观`全城实行宵禁。`保持原样；`你还好吗？`与`快跑！`保留原语气标点。两行排版或逐行分轨均须检查每一显示行。

**写入前必须实际逐条扫描本次新增、修改或用户指定清理范围内的最终text，包括对白／旁白、人物介绍的中文及译文所有行，排除worldview，清除所有句号并复查为零后再构造MCP请求。翻译、断行、改写、恢复或重建后重新检查最终载荷，不能只检查最初草稿。** 原始转录可留在内部记录，这两类字幕的含句号版本不得作为最终显示文本写回。用户要求“删掉句号”时，先查询本次目标范围已有对白／旁白及人物介绍字幕并清理，世界观及其译文保持原样，不只约束以后新增的字幕；保持其措辞、时间、样式、位置和未授权内容不变。

**写入后必须query读回本次目标的对白／旁白和人物介绍的全部实际text，再逐条校验句号。发现残留就用正式MCP更新相应文字，重新读回，直到目标范围无句号；不得仅凭写入成功、样例抽查或计划文案声明通过。** 若工具拒绝、无法读回或实际显示与读回不一致，报告未清理的具体范围与限制，不宣称全部完成。刷新预览核对清理效果；此检查针对字幕显示字段，不全局替换源文件、媒体URL、数字字段或其他工程属性。

## 单语与双语

- 用户要求双语时，中英文表达同一内容，并保持对应顺序。
- 翻译优先准确、自然和适合屏幕阅读，不擅自增加剧情信息。
- 为人名、地名、称谓和术语维护项目级词汇表，跨集保持一致并保留语气与人物关系；不翻译资产ID或内部字段。默认中文在上、目标语言在下，仅用户要求纯目标语言时移除中文。整套字幕双语时也翻译所选说明文字及人物姓名与已有身份；正式游戏译名另按标题规则。

## 呈现

- 用户只说“所有字体”“全部文字”或类似表达，且无法确定是否包括标题、人物介绍、世界观介绍或结局文字时，先用一个简短问题确认处理范围；用户明确说“所有字幕”或“字幕字体”时，直接处理当前范围内的全部字幕。
- 加粗、阴影、字号增减等相对样式要求以当前字幕样式为基础执行；例如“大两个字号”表示在当前字号基础上增加两级，不改成无关的固定字号。
- 用户明确指定外挂或烧录时，检查当前能力并按要求完成；未指定时使用可编辑字幕轨，不自行改为烧录。所需呈现方式不可用时说明限制，不静默切换方式。
- 字幕不得遮挡人物面部、关键动作、标题或互动选项。
- 人物说话字幕沿用工程默认样式与下方居中位置；介绍文字按各自排版规则处理，不因装饰降低可读性。

## 字体与样式能力

人物说话字幕（对白及旁白，timed_text）必须使用工程默认位置和默认样式，横排、画面下方居中，保持通常电影对白字幕的呈现。未收到用户明确的样式或位置要求时，不根据人物站位、背景留白、题材或个人审美自行赋值；不套用人物介绍或世界观的字号、white预设与位置规则。

写入时由工程默认配置接管位置、字体、字号、颜色、描边与对齐，不主动提交这些可选覆盖字段或自定义 subtitle_layout。若当前 MCP 合同要求显式布局，使用工程已确认的默认配置原值，按[字幕布局合同](subtitle-layout-handoff.md)提交；不得猜坐标、字号或将示例值当默认值。无法取得必需默认值时说明缺项，不编造。已有用户手动调整保留；仅改文字或时间不重置样式。只有用户明确要求样式或位置变化时才覆盖相应字段。

“更换字体”与加粗、阴影、字号是不同要求，分别核对当前可用能力。当前只支持默认字体时，保留默认字体；用户点名其他字体则说明暂不支持，不宣称字体已经替换。以后能力支持指定字体时可直接按要求使用，无需改变本规则。

对加粗、阴影、字号等样式，只执行实际支持且能检查生效的项；不把不支持的请求写成已完成。部分样式受限时，可继续完成其余明确且独立的要求，并说明剩余限制。无法获得当前字号或没有明确的字号步进含义时，不虚构“大两个字号”的换算。

## 完整口语与介绍文字

用户要求全部人物口语时，覆盖最终保留内容中的对白和旁白；用剧本校正专名和可确认的听写错误，不把未说出的剧本台词补成实录。无法确认的语音区间保留待核对记录，不能声称全部字幕已核准。

用户要求世界观介绍字幕时，读取 [世界观与开场前情](worldview-opening.md)：结合真实入口、入口第一集内容和实际开场画面，按内容尺度提炼“宏大背景与开场／局部设定与问题／生活事件与悬念”，只使用已有事实，用户未指定其他集时仅在正式第一集剪后开场安排一次，后续集不重复；用户明确要求某集前情则在指定集寻找安全可读的时段和留白，有标题时避开标题；不将独占前5秒作为必须生成新镜头的门槛；不是把总企划缩成简介，也不是任选一处空镜塞入说明。用户明确给定文字或位置时按其要求检查可行性，不擅自改写。

## 写入可编辑字幕轨

字幕数据必须经当前 MCP 写入可编辑字幕轨，同时遵循两份合同：

- [timeline_edit对接](timeline-mcp.md)：查询真实节点、轨道与片段，按当前 Schema 构造新增、更新或删除操作。没有轨道用 add track；已有目标轨道用 add clip；修改已有片段按工具支持的 update 或时间调整操作执行。
- [字幕布局合同](subtitle-layout-handoff.md)：规定三类字幕的 track_type、文字、位置与样式字段；保留原 MCP 外层，style 使用对象，font_size 使用字符串。布局放在对应操作合同允许的 properties 位置，不能把 update 示例直接套成 add 请求。

两份合同共同约束同一次 MCP 写入，不是分别发送两套数据。保存前 query 最新版本，保存后读回文字、时间和轨道身份；识别与语音对齐仍由实际语音能力完成。工具缺失或不支持所需字段时说明具体限制，不直接改工程文件、不猜后端接口，也不把聊天中的JSON、SRT下载文件或重做/烧录视频当作字幕入轨成功。用户明确要求文件导出时才按其要求另行交付。

若工程已有正确字幕而产品轨道仍为空，先检查版本、同步和消费者是否接入该轨道；保留已写结果，不反复重建字幕，不再转录同一段音频。将问题准确归为工程写入、产品同步或呈现限制，无法读取产品端时标记未验证。
