# 连续事件、切口与拓扑展开

继承已验证流程图的故事切片、交织、持续展开与局部恢复能力。统一创作循环改变交接方式，不能降低主线、支线和结局的事件密度。

## 从故事到本批节点

短故事先有明确因果和一个确定结果；完整方向不等于立即生成全部节点。用情绪脊在当前事件的期待、阻力和控制权变化处找岔点。每段先写成连续可读的事件梗概，读回，再按真实事件和待选行动划切口；不能先写“成功／失败／回主线”的结果框，再让编剧编理由。

每个剧情节点围绕一件主要事件，保留谁在哪里为何行动、实质交谈、阻力、应对和结果。第一集让普通观众在眼前事件中明白身份、目标与必要规则；一人一事一设定是信息节奏，不是机械人数限制。接任务、异地调查、遇袭逃生不能因为节省节点都挤在一集。同一事件的必要过程也不按动词数或等字数拆碎。

切口放在玩家尚未执行动作处。剧集建立现场压力和可执行办法；选择卡只承载问题与互斥行动；各后继先演所选行动及不同后果，不能连续选择代替后果。选择不能透露主角尚不知晓的地点、姓名、证据或权限。普通角色自行决定就写明理由，不留假问题后默认代选。

本批连续事件原文与切片保持对应，不在保存时压缩为结论句。标题另存，梗概不含 Markdown 标题、“若走某线”“无论哪条路”等作者编排。每份材料有冲突、入口事实、状态变化、真实出现的资产和 stop_boundary；选择动作属于边，首个后果属于目标节点。材料和剧本的关键事实一致。

## 展开所有有分量的方向

重要抉择的两边都要承受独立目标、阻力和代价，并产生各自下一轮决定。B 双翼与 C 双线交织是全自动非短作品的主要骨架，A 单侧深分支仅作补充。前中后继续发展，不能完成一个 B/C 模块就挂结局收工；不默认五六个选择已足够。

每条支线先从分出时真实处境写出一段连续经历，读回后切片；继续分岔同样处理。失去原件可寻找旁证，错信人可付代价补救，获得优势也可能欠下承诺。保留损失，不让每条失败都免费复位；不利选择不默认死亡，小结局不能成为省写支线的工具。

全自动逐批把规划方向落实成完整作品。未提交批次可修订，但已保存的好内容和用户手改默认稳定；质量问题只改依赖受影响的部分，不全图翻新。专家仅发展本批，保留末端和未来方向，不预填假内容。

## 共享事件与回汇

回汇共享的是从现在起可以共同经历的新事件，不是把不同人生重置为一个状态。逐来路读真实原文，核对主角已知消息、地点、伤势、持有物、权限、关系、承诺与已经完成的行动。共享段首句到末句所需条件必须在每条来路都成立。

只有段落后半段成立就从那里切出共享段；不要重演前半段。已救出的人不能再被绑，交出的原件不能再交，已公开的证据不能再讨论是否首次公开。外形相同的证件或腕带不代表相同权限。不同办法到同一场景仍须先完成各自所选动作，不得把“查档案”边直接接成“抢救电报”。

接不上时优先补该来路确有依据的取得过程、换合适落点、拆出共同未来事件；必要时独立发展，不能所有支线独立结束逃避交织。来路差异在入汇前表达，公共正文不并列甲乙两套事实，也不引用只在另一支发生的信息。检查入汇后的退出状态，时间与代价不能被重置。

机器不传播虚构状态。作者给出实际来路末句、所需条件和共享段对应句的简短证据，发现不成立只修对应支线；不写空洞“状态继承通过”，不要求剧本增加证明对白。

## 结算

继承四类结局：small 提前／局部收束；expected 兑现表层目标和题材承诺；failure 失败代价；main 更深真相或核心命题。没有用户覆盖时全作各至少一个，节点只取一个类型，用户结局总数包括全部类型。

期望兑现先是普通剧情，留有停下或继续的抉择。选择停下进入无出边的结局；继续经历新行动、发现或代价，再获得更深兑现。不同台阶的结果不同，不能换标题复用；真结局不能临时解除全部既定代价。主要结局的锁定分散在不同选择，避免末题好坏真菜单。

## 每次保存与续写

把实际切片、选择和后果保存为当前批次，稳定引用由 CLI 返回。选择与选项目标一批内完整连接，未完成末端明确待续且不标结局。写本批剧本与文字资产后立即可展示，不等待全作完结。读回确认正文完整而非只看界面截断。

新增人物／场景／道具可在事件或编剧准备中出现：统一创作协调者先核对其必要性、补入本集事实并保存资产，再冻结写作包；增强写作者不能偷偷越过写作包加事实。详见 assets 与 screenwriting。
