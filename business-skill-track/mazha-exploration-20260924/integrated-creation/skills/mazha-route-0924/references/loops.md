# 循环／调查型选择

这是显式按需能力，不是自由拓扑的默认生成方式。全自动自由创作保持无环，不为了增加玩法、分支数量或复杂度主动加入循环；专家模式也不因题材是调查就自动加环。只有用户明确要求循环／返回选择前，或当前画布已有循环需要保留、修改时，才加载本文件。单说“调查故事”不等于要求循环。

新增结构：普通剧情枢纽 → 选择卡 → 某选项的真实后果 → 返回选择前的枢纽。至少有可走的出口，能离开本循环并继续剧情或结束；出口不是一条实际仍回环的线。不能直接 choice→choice，无后果选择和无出口死循环都不合格。

回返意味着继续调查或重复行动，不默认时间倒流。再次进枢纽的正文必须兼容首次与回返，不能再次演出唯一死亡、再次领取已拿走的唯一物件或忘掉刚获知的信息。可将一次性引入留在环外，枢纽只演可重复的当前处境。信息、持有物、关系和代价不因回线消失。

## 内部声明与检查

检查用 PLAN 增加 loops 数组，每项 `{hub, choice, returns:[{source,target}], exits:[{source,target}], state_mode, repeat_contract}`。
- hub 为选择前普通剧情，必须直接接 choice；choice 至少一个选项先到独立后果再回 hub。
- returns 显式列出返回边，source 是普通剧情、target=hub。exits 是从环内走向环外的真实边，出口终能到真实结局（完整图）或声明的合法待续末端（本批）。
- state_mode 为 repeat_safe 或 conditional；repeat_contract 用普通话说明首次／重复进入如何相容、哪些事实保留、出口何时可选。
- 普通图仍无环；所有环须声明，不能把任意错误环当调查。检查报告保留实际节点与边，不能删回边、改成假终点后宣称整图 PASS。
- 环的无限重复不计持续展开、嵌套深度、结局阶梯或更多路径数。非短全自动的原复杂图门槛仍在。有环时图形审查返回结构检查结果及需要作者给出的有限前进路线证据；每条证据不能靠重复绕圈凑数，不谎报 DAG 检查已通过。

## 平台能力边界

现有前端图遍历有防环，播放器按边选择目标，可表达基础回跳；这不等于已验证 CLI 保存及视频重播的完整链路。首次使用先以现有 route help/schema 和实际保存读回验证，不修改后台、不绕过验证器。被拒绝时明确说明，可提出有限次展开的等价调查路径供用户决定，不能悄悄换型。

repeat_safe 用始终可选的真实出口和兼容重复观看的文本，不承诺隐藏变量。conditional 需要“查完线索才解锁／已调查选项隐藏／次数上限”等能力；必须查证真实变量、条件、更新与播放协议，当前未验证不能写自造字段。只画箭头不能宣称实现带状态玩法。

循环写作按首次进入路径先写各集，返回关系先用已核对的事件材料绑定，不冒称尚不存在的已存剧本；环内剧本齐全后，再以真实返回正文复核枢纽及后续。无法用同一正文承接时拆一次性引入与重复枢纽，不能让前情依赖互等造成永远不开写。
