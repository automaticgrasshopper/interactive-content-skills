# 图形规则：保留完整创作能力

全自动自由拓扑默认无环，循环仅限用户明确点名或维护已有循环，不由作者主动选择。全自动最终完整图执行本文件全部适用规则；专家局部批次只执行结构、选择后果、当前连续性检查，未到最终结算不要求凑四类结局。全自动中间批次可待续，最终不能以“本批通过”冒充全作完成。

内部规划节点 schema 与原 graph_check 保持一致：scene／ending 为 `{id,kind,source,next,ending_type}`，choice 为 `{id,kind,question,options:[{text,target}]}`。source 引用完整事件切片；这是检查用内部投影，不是平台 JSON。edges 只由 next/options 派生。平台类型与稳定 ID 交 CLI 适配；不把内部 id 当既有 node_ref。

检查入口 `python3 scripts/graph_audit.py PLAN.json POLICY.json`。policy 包含 scope (`full` 或 `batch`)、frontiers（当前合法待续 scene ID）、loop_authorization（仅用户明示 explicit_user_request 或已有画布 existing_canvas），plan.loops（见 loops.md），以及原检查器的 long_story、hard_counts 四项、required_endings、forbidden_endings、ending_override、exemptions。默认全作四类结局；未给硬数量用 null。工具报告不替代故事质量判断。

## 分类前提

先按故事整理解决用户目标与实际体量的冲突，再使用实际故事分类。用户要求短时长却又要求完整展开多阶段故事，不能仅填写短时长就豁免交织、深度与持续展开；须先得到对时长或故事范围的明确取舍。无时长要求且实际故事有持续展开空间时，保留非短故事复杂图形，不能默认缩短以套用简化门禁。机器只执行已确定的分类，不证明作者的体量判断合理。

## 图形硬门禁

- 基础：一个非选择入口，无不可达节点、无悬空边；普通图无环，声明的循环按 loops.md 单独检查；专家待续末端不冒充结局；scene恰有一个后继，choice至少两个不同目标，ending无后继。选项目标必须先落到独立剧集，不能用连续选择卡代替剧情后果。
- 数量：四项用户硬数量分别核对；一集不含选择，所有结局合计兑现用户数量。
- 结局：未指定数量或类型时，小结局small、期望expected、坏结局failure、真结局main各至少一个；包括短故事。用户覆盖只在确定用户范围时声明。
- 非短故事（>=15分钟）：必须有小结局；必须有真正双线交织（woven）；必须有展开回汇及至少两层分岔。用户类型覆盖或明确结构要求优先。短故事不强制交织、交叉与深度，默认四结局仍在。
- 展开后回汇：同一选择的两条路线，从各自不同的非结局剧集出发，以内部节点互不重合的路径进入同一后续非结局剧集，且汇合前至少一侧经过仅该侧可达的第二层选择。普通小菱形不算，即使别处有深层选择也不能补数。保留crossing检查键以兼容原恢复协议，但它表示展开后回汇，不把这种结构一概称为双线交织。
- 形状报告：单侧深分支为上述一侧展开；双翼为两侧均有汇合前的独立选择；双线交织还要求双翼能够进入两个互不可达的不同共享剧情段，两个共享段随后再进入共同剧情段。提供实际节点证据，不能用线条交叉、一个共同汇合点或串联菱形冒充交织。B双翼展开和C双线交织作为默认主要骨架，A单侧深分支只作补充；A单独不够，只有B而没有C也不够。非短故事woven必须PASS；仍不要求额外单独凑一个A。用户明确简单结构或固定数量无法容纳交织时，才用原话声明woven豁免，不因难写、节约节点或已存在B而豁免。
- 深度：第二个选择位于前一个选择的部分支路上，其他支路不会同样必经它，才增加嵌套层级；普通串节点或串联公共小菱形不算第二层。
- 三个及以上主要结局时，计算各结局首次变成唯一可达的锁定选择，至少分布在两个不同选择；不允许最后一题统一分配全部主要结局。小结局不参与主要结局锁定统计。

非短故事另须通过以下整图门禁，短故事不强制。它们提供最低结构保障，不代表达到数字就应停止有意义的创作：

- sustained_growth：至少4个持续展开的选择，每个至少两条选项先经历非结局剧集，并各自进入不同的下一选择；其中沿同一路线至少经过3个这样的展开位置。两侧直接回同一个公共选择不计入，单个B/C模块、延长直线或多挂结局不够。
- continuation_balance：除逐级期望结算和最终收尾选择外，至少三分之二选项通向后续仍有选择的剧情。用一串直线拖延后直接结束仍视为退出方向，不因加长就算继续生长。报告逐个列出继续与收尾的选择。
- ending_ladder：沿一条继续路线至少存在两次期望结算机会；每次停下可到不同的expected结局，继续必须经过普通剧集再到下一选择，最终仍能到main。ending本身不连出边，单次最终选择直达结局不能算阶梯。

用户明确固定数量或简单结构与这些默认门禁冲突时，只豁免确实无法兼容的项，并引用对应原话说明原因；不能改用户数量来满足默认门槛。机器不判断期待是否真正兑现，作者负责不同层次的结果、来路代价和真结局含义。

无环全图由保留的 graph_check.py 检查并给出路径数、形状及节点证据；有环图不能宣称有限总路径数或直接跑 DAG 检查。循环本身不计深度／持续展开。按 loops.md 检查环、出口及人工复杂度证据。
