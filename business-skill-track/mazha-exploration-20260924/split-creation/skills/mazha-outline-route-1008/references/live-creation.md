# 路线与编剧交替真实保存

全自动与专家只改变范围。完整因果与方向可以提前在缓存规划，画布按实际当前单元保存长出，不先创建整作空图与全资产再批量补正文，不 sleep 或写空进度表演创作。

保存当前剧情节点和真实前驱；选择卡与全部选项、即时后果入口一起提交。然后按 skill-handoff.md 交给独立编剧逐节点写作，每段累计正文、新资产与修订分别调用 CLI 并等待返回。当前节点最终写完、保存和读回完成，才继续展开下一段路线。编剧正文分段细则只在编剧 Skill，不在此重演。

资产随当前事件补齐，保持原有引用。中断恢复读当前后端和已完成正文，只补未完成单元，不重放旧缓存。CLI saved 证明项目文件已保存，不证明前端已收到；实际 UI 尚未同步就报告同步情况，不用回放假装新写入。不等待动画后才继续后端业务，前端可以排队呈现真实版本。

专家在本批所有节点正文及资产读回后按本轮停点结束；未完成末端是待续普通剧情，不标结局。全自动完成全部方向与正文才终验。不发明平台没有的剧本完成布尔字段，不把尚未写完的工作稿当本集完成。
