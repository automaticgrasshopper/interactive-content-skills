# 写到哪里，真实保存到哪里

自然语言本集剧情之后直接写正式剧本。形成可读、格式正确的完整行动段时，用 CLI `script set --text <正文文件路径|->` 保存当前累计纯文本正文；资产引用按节点 assets 和 CLI 合同维护，工具返回后继续写下一段。不先写完整剧本再拆段补交，不 sleep、刷空工具或写假进度。极短节点不硬拆，有多个自然行动段时保留前后两次实际正文写入。

需要新资产时先核对当前事实与已有 ref，按 assets.md 保存读回，然后将新增段落写入同一节点的累计正文，同步实际节点资产关联。事实或连接要改变则返回路线协调，不由正文擅自新增规则、来源或结果。

可以直接修订当前正文，使用 CLI script edit/set 保留无关手改、资产关联与媒体；不走另一轮底稿、增强或写作验收。写完后实际保存、读回目标正文和资产引用一致，才返回节点完成。没有平台完成字段不自行发明。

每个有意义的保存分别工具调用，不把全剧所有操作包成一次调用。内部材料和搜索笔记不进正式剧本。不等前端动画，页面按真实 SSE 版本排队展示；保存成功不代表页面已经同步，尚未同步要如实说明。协调中的单节点完成不结束整批运行，直接用户单节点请求完成后可以正常回复。
