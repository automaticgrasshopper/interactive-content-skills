# 按真实保存展示创作

先按 modes.md 确定方法。逐段生长保存当前事件、选择及全部即时后果入口，再由独立编剧逐段保存正文；当前单元完成才生长下一段，不先创建整作空图。六种形状只约束这一方法的首次开场，后续仍用情绪脊。

普通完整拓扑先按 continuation-handoff.md 确认状态；route generate 路径跟随 cli-topology.md：主线与每条支线的实际切片写进画布就可以展示，branch-shape 不写画布，landing 是待展开而非完成剧情。持续完成全部分支、结局并通过真实 check/complete，不能用自己的逐段限制截断完整 CLI 规划。【一键拓扑】止于全图；整作文字创作随后在同一 Run 为全部实际剧情节点逐个编剧。

已有图的普通 route edit 增量路径按 continuation-handoff.md 逐个完成尚未展开的事件与选择后果，保留现有引用与正文；不新造整作空图，不用旧 complete 证明本轮完成。

新文字资产随实际事件补齐，保持引用。每次有意义的内容更新分别调用 CLI，等待真实回执再继续；不 sleep、不刷空工具、不写完再拆保存表演。前端独立消费真实版本队列，后端不等待动画。

中断恢复读当前后端，保留用户手改、删除及已完成内容，只补未完成部分；active plan 按 CLI 恢复，不新建规划逃避错误。saved 只证明项目文件保存读回，不证明前端或远端投影收到。同步未知如实说明，不用缓存回放假装新创作。不自造剧本完成字段。

默认确认大纲的开场单元按六种形状完成全部本批事件、选择与实际后果，不固定单集。后端可先保存合法局部图，再逐节点编剧；前端仍完整播放开场梗概→构思→该节点正式剧本→回图→选择问题和选项→每条分支后果的梗概、构思、正式剧本与回图，不一次铺满空节点或用摘要代替正文。整批播放结束后展示整体路线再移交，后端不等前端动画继续执行。

局部本批可以有待续普通剧情，不能标假结局；完整拓扑不能留待展开方向，整作剧本不能缺正文。默认开场单元也是明确授权的完整本批任务，其所有本批正式稿、有效连线和必要形象确认齐备后可交接。移交效果仅在授权任务真实完成、Run 结束且展示排空后发生；局部任务、停止或刷新不触发。

后台实际保存与前台播放相互独立：提前返回的文本和图片进入展示队列，不抢占或清除尚未完整播放的步骤，不因 Run 结束缩短字速或标点停留。每个场面与选择后果按当前节点完整打字、写剧本、回图及连线；连线等待实际动画完整结束，不写死秒数，图片按自己的审核、特效和玩家确认门槛推进。页面刷新恢复前台同一请求的步骤、游标、剩余停顿/特效、确认状态与待播队列，以实际播到的位置继续；后台已完成不跳到终点，新请求修订才废弃旧队列。
