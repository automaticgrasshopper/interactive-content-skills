# 业务接口声明

本文件是资产图片生成师与工程侧之间的字段合同。工程按这里声明的字段名称、类型和层级取值；图片版式和prompt内容要求由其他 references 文件负责。

## 接口规则

- 顶层固定为 `角色资产`、`场景资产`、`道具资产`三个列表。
- 每个资产结果通过 `目标资产名称`和`资产类型`对应上游文字资产，不创建资产工程ID。
- `art_style_id`、画风 `prompt`和`negative_prompt`属于运行时输入；`art_style_list`返回的画风参考图必须忽略，不读取、不下载、不绑定、不传入图像模型，也不作为输出字段。
- 字段名称、顺序、列表结构和嵌套层级不得改名或增加别名。

## Skill 输入字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `角色描述` | list<object> | 条件必填 | 与场景描述、道具描述至少一项非空。 |
| `场景描述` | list<object> | 条件必填 | 与角色描述、道具描述至少一项非空。 |
| `道具描述` | list<object> | 条件必填 | 与角色描述、场景描述至少一项非空。 |
| `画面比例` | string \| null | 否 | 游戏成片比例，仅作为构图上下文；资产图固定16:9。 |
| `视觉风格` | string | 是 | 用户可见画风名称。 |
| `art_style_id` | string \| null | 否 | 库内画风用于 `art_style_list`定位；自定义风格为 `null`。 |
| `附件` | list | 否 | 身份、场景、道具、排版、风格或已有资产参考图。 |
| `执行模式` | string | 是 | 枚举：`Prompt与生图`、`仅查看Prompt`、`修改并重新生图`。 |
| `目标资产名称` | list<string> \| null | 否 | 为空时处理输入中的全部资产。 |
| `修改要求` | string \| null | 否 | 修改已有prompt或图片时使用。 |
| `已有图片资产` | list | 否 | 修改并重新生图时按资产名称绑定。 |

### 运行时画风数据

库内画风由 `art_style_list` 定位；自定义风格由上游已确认或用户明确提供的最终风格资料形成：

```text
画风记录 object
├─ art_style_id string | null
├─ 名称 string
├─ 参考图 image
├─ prompt string
└─ negative_prompt string
```

本skill只读取画风记录中的 `art_style_id`、名称、`prompt`和`negative_prompt`。即使Tool返回 `参考图`字段，也不得读取其图片内容或将其加入任何资产的参考图列表。

两种来源的 `prompt` 都必须是去除首尾空白后非空的字符串；缺失时暂停并请用户补充。自定义风格 `art_style_id`为 `null`，`negative_prompt`可省略或为空，用户风格参考图可选。自定义风格资料在运行时原样继承。

## Skill 输出字段

三个顶层列表中的每个资产对象使用完全相同的结构：

```text
角色资产 list<object>
场景资产 list<object>
道具资产 list<object>

资产对象
├─ 目标资产名称 string
├─ 资产类型 string
├─ 画面比例 string
├─ 参考图使用说明 string
├─ 中文prompt string
├─ 中文负面prompt string
├─ 必须保持一致的内容 list<string>
└─ 图片资产 image | string | null
```

## 字段约束

- `资产类型`只能为 `角色`、`场景`或`道具`，并与所在顶层列表一致。
- `画面比例`固定为 `16:9`。
- `中文prompt`必须合并库内画风 `prompt`的一次性中文翻译或自定义风格 `prompt`原文，以及当前资产的中文正向生成要求。
- `中文负面prompt`必须合并库内画风 `negative_prompt`的一次性中文翻译或已提供的自定义风格 `negative_prompt`原文，以及当前资产类型的中文负面约束。
- `参考图使用说明`只描述当前资产实际绑定的用户附件、排版参考或已有资产图，不得包含Tool返回的画风参考图。
- `图片资产`在成功生图时保存图像工具返回对象、URL或工程可存储引用；仅查看Prompt时为 `null`；生成失败时为 `null`，失败原因由运行日志记录，不增加新的业务输出字段。
- 某类没有目标资产时输出空列表，不创建“本轮没有资产”等虚拟对象。
