## 实现

- 人物生图同步准备稳定声线、匹配音色和一句人设台词，首次形象确认旁展示自然中文声音类型与原生音频播放条。台词通常8—20字、最多25字，一口说完；禁止客服招呼。
- 只有当前图片审核通过、完整呈现，音色ID及试听可用且浏览器读到有效音频时长，才能确认。有声音设定但试听未就绪或失效时停留；场景、道具、无声角色豁免，旧无声音设定项目保留原流程。
- 使用 CLI 真实 voice_binding 的 voice_id / preview_audio_url，attributes.voice 提供自然中文类型；不新增未声明工程字段。新版绑定优先于陈旧 audio 结果，文字编辑保留声音绑定。
- 只有本次角色台词已生成并核听通过后才保存试听绑定，音色库通用预览不能冒充它。改图不重做合适音色，后续对白镜头必须复用绑定。
