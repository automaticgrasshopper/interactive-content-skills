# 第一节与首个小分支

从读通的短故事开头展开第一节，不先写完整长故事、全部支线或全图。第一节围绕一个眼前事件，用具体地点、人物行动和必要的实质交谈讲清身份、关系、目标及必要设定。控制开头的信息涌入，不机械限制人数或动作数。

让这个事件推进到第一个有依据、尚未执行的选择。选择之前只建立压力和可选条件，不能先让主角做完某项行动再询问。选项一般为 2—3 个，必要时到 4 个；用户明确要求优先。用主角当时知道且能执行的动作写选项，不用作者知道、主角尚不知道的真相泄题，也不把选项写成“走好结局／走坏结局”。

为每个选项分别写一段具体直接后果：实际采取什么行动，谁怎样回应，得到或失去什么，因此落到什么新处境。后果应足够编剧展开一场戏，不是“关系变差”“进入调查线”等标签。每条正文只写本条发生的事，不夹带“若另一条路线……”或主支线编排说明。标题和连接说明放在正文外。

首轮在这些后果已经发生、差异可见时结束。可以留下新的压力与悬念，但不继续生成第二层选择、后续扇面或全部结局；不要把未续写的开放落点伪装为故事结局。若用户的局部要求本来就是分出两个结局，则写出真实结算。短故事可以完整讲到结尾，实际展开的节点仍只到首个选择的后果。

默认面向用户展示第一节、选择问题及每个选项对应的后果，关系清楚即可。短故事是保留的创作依据，用户要看时完整展示。交付后停止，不自动附上一整套后续方案或内部分析；可以用一句简短邀请让用户指出想继续看的地方，不要求逐步审批。
