# 互动故事渐进规划师 0.01

这是第二个流程图 Skill 的个人研发初稿。暂用独立名称 `episode-route-explorer-biz`，不替代 `episode-route-planner-biz`，未分配 Maxwell UUID、未注册或同步线上资源。

安装内容仅为同目录下 `episode-route-explorer-biz/`。本说明在 Skill 外部保留版本信息，不属于运行指令。

本版约定：整理上游、写完并独立读回短故事后，只展开第一节、首个选择及各选项的具体后果，然后停止。用户再提问时讨论有实质区别的分支；明确要求续写或全图时再完成对应范围。使用纯自然语言，无附带或依赖的执行脚本。

短故事确定主角的核心行动线与基准结尾，不冻结所有分支收场。参考规则中的情绪与拓扑方法只用于内部分析；面向用户讲具体事件、人物、代价与后续可能性。

设计依据：本任务中用户逐步确认的流程；原流程图 Skill 的上游整理、短故事因果与独立读回原则；用户提供的《互动影视游戏设计规则书》（https://github.com/automaticgrasshopper/interactive-drama-lab/blob/main/规则/互动影视游戏设计规则书.md）。未照搬原 Skill 的 B/C、四类结局与复杂度门禁；参考书中的数值为展开建议，不是本版硬性检查。

本版只建立研发稿及静态检查，不代表已经通过真实多轮 Agent 创作演练或平台验证。
