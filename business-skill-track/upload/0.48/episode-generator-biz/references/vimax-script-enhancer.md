# ViMax Script Enhancer

本 reference 只在Screenwriter已输出完整草稿后使用。目标是把已经成立的剧情扩成清楚、可拍、能顺读的最终剧本，不改变冻结故事、拓扑、梗概、选择、结局或停止边界。

## 输入边界

只读取脚本生成的当前`enhancer-inputs/<episode-id>.txt`。该输入必须完整包含当前Screenwriter草稿、当前集停止边界、本reference和`chinese-dialogue-craft.md`；缺少任何一项不得增强。不得读取验收答案、旧增强稿、后续正文或其他路线。

## 增强任务

完整通读草稿与中文话茬reference后，一次性重写全场。Enhancer拥有改写剧本表达层的完整权限：可以重排不改变因果的场内动作、重写全部对白、增删或拆并话轮、补充停顿与反应、改变句式和场面节奏；不要求保留Screenwriter原句。唯一硬边界是不得改变冻结剧情事实、人物行动结果、选择、结局和停止边界。

1. 保留草稿中的事件顺序、行动结果、场景、人物、道具与结尾位置。
2. 把过度压缩的动作补成观众能连续看见的接触、阻力、反应和结果，不靠作者总结跳步。
3. 人物首次进入时，用现场动作、频道来源、自然报号、职务称呼或关系称呼说明其当下身份；已清楚的内容不重复登记。
4. 按`chinese-dialogue-craft.md`执行“承重句与普通话茬”“补口语组织”和反字幕式对白规则。让问题、命令、请求、反驳和迟疑得到现场回应；补入人物当下真正需要的称谓、对象、承接、态度、改口、重复和关系指向，不把话轮压成信息骨架。
5. 台词使用直接可懂的现代汉语，允许危急口令简短，但相邻话轮必须接得上。
6. 结尾停在草稿已经建立的压力或判断上；不得提前完成停止边界列出的后续独占动作、核验、选择或结果。

允许彻底改写草稿，但不得新增角色、场景、道具、规则、证据来源或未来情节，不得改变谁做了什么、动作造成什么结果以及本集停在哪里；不得把同一身份和风险在旁白与对白中反复解释，不得加入审稿标签、作者判断、主题金句或制作话术。

## 输出

把增强后的完整连续场景写入`enhanced-screenplays/<episode-id>.md`。只输出剧本正文。该文件是唯一正式正文；后续只做确定性结构验收，不再生成第三版正文。
