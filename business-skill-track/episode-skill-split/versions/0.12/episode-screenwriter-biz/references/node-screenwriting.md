# 单节点冷读

本阶段只判定正式剧本能否交付，不提供写作方法，不在正文里逐项补证明。只读冻结写作包、正式剧本和本文件；不读全图、旧稿、后续正文或预期答案。

按结果检查：

1. **路线与边界**：事件、人物、资产、分支准备和结尾忠实于冻结材料，没有提前演出后续独占事件。
2. **戏剧节奏**：每个段落或交流段都带来新信息、新阻力、新行动、新关系变化或新结果；同一判断成立后没有继续解释、确认或举证。
3. **双因果**：写作包提供双因果时，人物的关键行动同时由当前事实和人物对事实的理解导致；删去人物在意之事或关系状态，行动不会仍然原样发生。冻结的`human_change`已经成为可观察的选择、拒绝、隐瞒、让渡、保护、风险承担或对待方式变化，而不是情绪标签；它为`later_effect`留下真实行为条件。写作包未提供时，正文没有擅自制造人物创伤或关系转折。
4. **首次理解**：当前观看路径首次出现的人物，普通观众能自然理解是谁、与眼前事情的关系、为何此刻需要他；不要求`identity_anchor`原词出现。写作包为`viewer_mode=entry`时，只凭正文能否跟上第一轮真正改变局面的行动：谁为何行动，眼前场景特性或世界规则怎样影响行动。只要求理解当前作用与代价，不要求解释历史、来源或隐藏真相；不得因本项增加介绍段或证明对白。
5. **场面与空间**：正文可见可听；剧情需要的位置、进出和物件归属前后不矛盾；没有为了交代连续性而记录无效走位或摆出终场队形。
6. **对白**：人物说话对象和回应关系清楚，语言像当前关系中的人话，没有作者结论、资料搬运或连续字幕骨架。
7. **分支与停止**：分支节点的每个冻结行动已经可执行且受同一现场压力约束；正文停在当前边界内。

检查项只能引用正文已经自然存在的最小证据，不能要求正文为验收增加一句解释或一个动作。任一项失败，指出失败所在的现有段落，废弃整稿并从同一冻结输入重新完整复写；不得在成品上贴补，不得修改拓扑、底稿事实或其他节点。
