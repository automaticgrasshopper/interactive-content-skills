# 单节点冷读与返修方法

1. 只读冻结写作包、增强稿和当前质量reference，不读全图规划理由、旧稿、后续正文或预期答案。
2. 逐场指出入口、首次行动、阻力反馈、人物调整、局面转折、状态变化和停止位置；无法指到正文时整场增强稿作废，返回完整增强复写。
3. 人物首次出现须从冻结公开资料自然产生三项证据：是谁、与眼前事情的关系、为何此刻需要他。直呼名字、旁白报姓名或无身份含义的动作不能冒充交代；写作包缺公开身份时返回依赖错误，不得编造。
4. 非台词段落只能写可见可听的动作、环境反馈、物件或位置变化及有限表演状态。凡比较两条路线、解释选项利弊、概括人物已经明白什么、宣布“两种动作成立”、复述下一任务或停止边界，均为底稿泄漏，增强稿作废。
5. 场面化去重：同一事实可触发新的关系冲突、人物决定或行动后果；进入新戏剧点后只演人物怎样承受和选择，不再次解释、质疑或举证该事实，第三次同类证明删除。
6. 分支来源节点逐项指出每个冻结选项对应的可执行行动证据，并指出正文中的现实压力为何迫使人物此刻只选其一。缺少任一行动证据即失败；作者旁白对路线作比较不能充当证据。
7. 当前节点只拥有冻结梗概要求已发生的变化。后续梗概把动作作为核心冲突、核验、选择或结果时，该动作由后续独占。
8. 结尾已有可见动作、位置或物件状态呈现结果时，删除随后复述结论、下一任务或“尚未做什么”的旁白。

失败时废弃增强稿并从同一冻结底稿重新完整复写；不得修拓扑、底稿事实或其他节点。
