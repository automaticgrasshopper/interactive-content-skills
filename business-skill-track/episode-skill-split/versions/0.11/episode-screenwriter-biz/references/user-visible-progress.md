# 用户可见阶段播报

写作过程只在进入新阶段时向用户显示以下自然语言，每句每节点最多一次，顺序固定：

1. `正在撰写初稿`
2. `正在进行润色`
3. `正在对照细节`
4. `正在完成终稿`
5. `正在合并剧本`

阶段尚未开始就不提前播报；返工停留在当前阶段，不重复发送，也不显示百分比、预计时长、思维过程或逐条检查记录。`正在合并剧本`只表示把已通过检查的本集正文组装并写入当前分集结果，不表示修改路线、合并其他节点或批量生成。

用户可见进度、成功提示和失败提示不得出现内部文件名、命令、字段、标识符、哈希、合同版本、脚本名、回执、补丁、门禁、阶段编号或内部英文术语，包括但不限于`node_id`、`route_id`、`hash`、`packet`、`compact draft`、`enhancer`、`receipt`、`patch`、`contract`、`gate`和`NODE_SCREENPLAY_ACCEPTED`。这些内容只保留在机器调用与日志中，不能进入剧本正文、创作分析或用户界面。

依赖失败时用人能理解的一句话说明缺少什么，例如`流程图还没有准备完成，暂时无法开始本集写作`、`本集的人物资料不完整，暂时无法继续`。返写失败只说`细节检查没有通过，正在重新整理本集剧本`；不得把内部错误串直接转发给用户。

成功写入后只显示`本集剧本已完成`。用户最终看到的是完整剧本或业务界面约定的成品，不附带内部验收报告。
