# 单节点冷读与返修方法

1. 只读冻结写作包、增强稿和当前质量reference，不读全图规划理由、旧稿、后续正文或预期答案。
2. 逐场指出入口、首次行动、阻力反馈、人物调整、局面转折、状态变化和停止位置；无法指到正文时整场增强稿作废，返回完整增强复写。
3. 逐场做一次空间接力冷读：从开场开始，按正文记录每个人当前所在、相对谁或什么、是否在场，以及关键物件在谁手中或哪里。每次移动、进出、换位和换手后立即更新；若下一动作无法从上一状态发生、人物无动作便换位或进出、物件无交接便换手，整场增强稿作废。只检查剧情会用到的空间关系，不要求绘制房间或补无关走位。
4. 单独追查所有`取出`、`拿起`、`接过`、`递给`、`放回`和同义动作：正文必须能逐步指到物件此前所在、交接动作和此后持有人。身份上的`保管`不能代替现场来源，找不到来源或换手过程即作废。
5. 逐个交流段确认发言者、听话对象和双方当时的空间条件能从正文看出。两人场景且对象始终唯一时不重复标注；多人同场、隔门隔桌、有人中途进入或发言同时取物移动时，对象或位置一旦可能混淆就必须由有因果作用的动作重新锚定。
6. 人物首次出现须从冻结公开资料自然产生三项证据：是谁、与眼前事情的关系、为何此刻需要他。直呼名字、旁白报姓名或无身份含义的动作不能冒充交代；写作包缺公开身份时返回依赖错误，不得编造。
7. 非台词段落只能写可见可听的动作、环境反馈、物件或位置变化及有限表演状态。凡比较两条路线、解释选项利弊、概括人物已经明白什么、宣布“两种动作成立”、复述下一任务或停止边界，均为底稿泄漏，增强稿作废。
8. 场面化去重：同一事实可触发新的关系冲突、人物决定或行动后果；进入新戏剧点后只演人物怎样承受和选择，不再次解释、质疑或举证该事实，第三次同类证明删除。
9. 分支来源节点逐项指出每个冻结选项对应的可执行行动证据，并指出正文中的现实压力为何迫使人物此刻只选其一。缺少任一行动证据即失败；作者旁白对路线作比较不能充当证据。
10. 当前节点只拥有冻结梗概要求已发生的变化。后续梗概把动作作为核心冲突、核验、选择或结果时，该动作由后续独占。
11. 结尾逐人回放最后一次明确位置变化，并逐物回放最后一次换手；集合句只能概括已经逐人写出的状态，不能创造新位置。已有可见动作、位置或物件状态呈现结果时，删除随后复述结论、下一任务或“尚未做什么”的旁白。

失败时废弃增强稿并从同一冻结底稿重新完整复写；不得修拓扑、底稿事实或其他节点。
