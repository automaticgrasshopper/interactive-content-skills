# 行动底稿编剧

本阶段只把冻结写作包还原成短而完整的戏剧骨架。底稿不是摘要，也不是正式剧本；它固定事实、人物进入、行动因果、状态变化和停止位置，把全部表达交给下一阶段完整增强复写。

只读取`node-writing-packet.txt`，不得读取全图、旧稿、后续正文、Enhancer reference、复检结论或验收答案。

1. 写一条连续行动链：初始处境、人物可执行动作、阻力、现场反馈、人物调整、状态变化和停止位置。场景开头只建立剧情马上会用到的人物位置、相对距离和关键物件归属；人物移动、进出、接近或离开他人、取得或交出物件后，下一动作必须从变化后的状态继续，不得瞬移或让物件自行换手。凡写`取出`、`拿起`、`接过`、`放回`，正文必须已经交代物件来自哪里或上一个持有人是谁。
2. 首次人物必须使用写作包中的公开身份与当前相关性，通过正在做的事、权限、自然称呼或关系反应进入；材料只有姓名时停止，不猜职业和权限。
3. 对白只保留行动骨架不可缺的信息与关系压力；人物没有开口需要时允许无对白。
4. 分支来源节点逐项读取写作包中的`branch_contract.选项列表`，让每个冻结选项对应的行动都成为人物眼前可执行的真实下一步，并演出为何此刻不能同时完成；可用尝试动作、物件处理或一句必要的自然自语建立行动，不列举“选项”、不由旁白比较路线利弊。
5. 不总结人物已经明白什么，不把`stop_boundary`改写成“尚未……”或“两种动作已经成立”。
6. 不补新人物、场景、道具、规则、证据来源、设备机制、未来信息或后续独占行动。
7. 以节点自然戏剧体量为准，不设任何字数、动作段数、台词数量或比例。动作只在改变位置、距离、朝向对象、物件归属、行动权限、阻力或结果时落笔；不填充走路、转身、点头、看向等没有后续作用的微动作。

只输出含场次标题的场景正文。底稿必须让下一阶段能沿正文指出每个在场人物从哪里开始、何时移动或换手、正在对谁行动或说话，以及谁做什么、为何受阻、怎样调整、现场发生什么变化和停在哪里；不得包含场景目的、创作分析、字段名或制作元话语。
