# 完整故事与切片

## 先把故事讲明白

先用普通话在creative_brief讲清：主角为什么来到这里、眼前要完成什么、谁或什么阻止他、核心异常究竟是什么，以及关键能力能做什么、不能做什么。相同事物使用稳定称呼；不要把同一对象换成多个技术名词制造信息量。遵守用户题材和设定，作者自加的机制只保留推动主要矛盾所必需的部分，优先复用已建立的规则。增加分支靠人物行动、资源取舍、关系和后果，不靠每条路新增一套世界规则。

企划未解释的必要前提，先补清其含义与限制，并在授权的企划交接中同步，不能让大纲和故事各说一套。技术名词、资产描述和作者脑中的背景不等于读者已知。故事正文在规则第一次影响行动之前，用具体遭遇、操作结果或人物解释交代它；不依赖读者翻设定表才能看懂。可以隐瞒真凶和动机，不能隐瞒理解眼前危险、行动和选择所必需的基本事实。

## 主线

先把企划中必要的目标、欲望、阻力、人物关系与世界规则写成从开场到最终结算的完整主线。真相由行动与发现展开，不把资产卡、结局标签或提纲当故事。不预先用软节点建议压缩路线；用户固定集数时必须兑现。

在写故事时组织压力、期待、现实变化与控制权，预留四类不同结算：小结局是退出或提前收束；期望结局兑现表层目标与类型承诺；坏结局演出失败代价；真结局完成更深真相或核心命题。正式字段以 main 表示真结局、expected 表示期望、failure 表示坏结局、small 表示小结局。每类默认至少一个，不能一节点多贴标签。用户指定的结局总数包含所有类型，不额外加小结局。

期望兑现节点仍是普通剧集：目标已解决，但留下尚未执行的最终抉择。停下进入期望终点；继续必须经过进一步的行动、揭露或代价，再进入真结局。任何正式结局节点都无出边。递进是创作偏好，不强迫违背用户指定的故事。

主线冻结前，以第一次接触故事的读者身份顺读正文：每个关键行动为何发生、凭什么能做、造成什么变化，都能在此前事件中找到依据。反转必须有前置线索和发现过程，不能到结尾集中宣布另一套真相或临时获得解决问题的权限。读不懂的地方现在补写或简化；解释必须进入正文，不能只在brief或作者检查说明里声称已清楚。冻结前逐一核对剧集停止点与下一集开头：若前段把行动留给玩家决定，正式图必须安排选择；若是人物自行决定，本段就写清决定及理由，不能以待选语气结束、下一段默认代选。这里只核对作者写出的真实动作，不按关键词机械判剧情。

主线写完，从开场到结尾扫描命令、交易、求助、隐瞒、牺牲、有限资源和不可逆操作。为可采用裂口先安排原文切口，保证选择前未执行任何选项；原主线行动成为一个选项，行动及后果留在下一剧集。主线冻结后不得为补图改原文、剧集切片或原走向。

## 支线

对每个选项写出直接后果，再根据新处境判断结束、继续、再次选择或回汇。继续路线重新扫描它自己的决定裂口，不以已有结局数量足够为由停下。保留决策、关系和调剂选择；每个动作互斥、可执行、有不同可见后果。

鼓励开扇与交织。重大路线完整承受自己的目标、阻力和代价，可以长于主线，可以完全独立结束。回汇只共享已经成立的共同任务，不抹去来路中的知情、伤势、持有物、关系或承诺。后文不能依赖另一支路独有事实，不能重演已经完成的过程。作者负责这些剧情判断，机器不传播虚构状态。

每条新增支线从分出时的事实连续写到回汇或结局；选项后新一轮分岔也先写完整故事，再切分。共享段只保存一次，沿任一路径串联各段和选择动作应当成为完整故事，不写“若走另一条路线”等并列说明代替当前事件。

连接回汇前，用每一条来路实际读到的事实检查共享段的第一项行动：人在哪里、拿着什么、知道什么、已做过什么。缺少录音就不能直接播放录音，已交出的原件不能再次交出，已经公开的证据不能又讨论是否首次公开。应在缺项支线中写出取得条件的完整过程，或让它进入另一个成立的共同节点；不能用“同样抵达”“重新汇入某状态”一句话代替事件，也不能改变冻结主线来迁就支线。共同节点写所有来路都成立的一次具体事件；来路差异在汇入前演出，不能在共享梗概中并列“若走甲线／若走乙线”，让编剧再次选择剧情。证件、钥匙或腕带的外形相同不代表权限相同，每条来路都要实际取得后续所需权限。共同段也要核对退出状态：两条来路的地点、已花掉的资源、已取得的权限及证据不能在回汇后被重置；完成同一任务的不同顺序应留下可感知的代价、关系或信息差异，并在后文承接。支线结尾若提出新的互斥抉择，就落实选择卡和后果；若人物已因具体理由自行决定，写明理由和行动，不留下假选择。

## 剧集材料

每份 complete_story 是连续可读故事，episodes 是它按顺序、无遗漏、无重叠的原文切片，text 不另写缩略摘要。每集自然写清处境与目标、人物行动、阻力或调整、可见变化与停止位置；不要求模板段数、字数、对白或表演细节。编剧只需将既定事件展开成戏，不需要补关键事实、行动与结果。结局也要完整演出结算。

选择卡只显示问题和动作，不承载独立剧情；选择前的剧集建立可执行条件，后继剧集演出所选动作与后果。一集就是一个非选择剧集节点，不能把独立剧情藏进选择卡，或将一个剧集偷算成多个slot。

作者最后沿路线顺读，不把“句子通顺”“切片相等”当成故事已经清楚。编剧不应再决定人物生死状态、物件来源、能力边界、动机或转折原因；这些关键事实必须由本阶段正文落实。末段的救援、传输、权限解除和人物倒戈同样受此前规则约束；不能先承诺不可逆代价，再无依据地全部返还。后来的真相若推翻此前说法，要让人物发现并解释说法为何不实，不能把两个矛盾版本都作为作者事实。确认用户必保事件与禁区、完整因果、回汇承接、各类结局兑现及选择未提前发生。发现问题只修对应支线；若错误必须改冻结主线，明确说明被锁位置与原因，不能自行解冻。
