# 当前画布与用户编辑

## 当前图是事实源

每次处理已有项目，先重新取得当前项目revision、全部节点和边（分批读到结束），再按当前显示集号或唯一标题解析稳定node_ref。剧集与选择卡分别计数。禁止使用用户操作前的快照、旧route候选、冻结主线或完整路线模板覆盖当前图；旧文件只能在明确恢复请求下作为指定对象的历史材料来源。

用户已在画布删除的节点视为已删除，插入的节点视为已存在，重连结果视为当前连接；不要求用户在聊天重复说明。继续生成剧本、故事板或视频不授权增删、恢复或重连路线。读取当前节点的最新版正文和媒体；后续写回前再核对revision，变化后重读重建局部请求，不覆盖并发用户操作。

## 按用户动作执行

- 删除：删除指定节点及相连边，清理悬空选项目标、默认跳转等派生引用。保留其余节点原文、稳定ID、剧本和媒体。用户已删除时不得再恢复，也不自动新建替代节点。新增连接只有用户明确要求或现有平台删除操作已确定时才采用；若需补接缝，先指出最小范围。
- 新增或插入：使用当前图定位前后锚点；只新增用户要求的剧情段和必要连接。不得重复创建画布上已经插入的空节点，不因插入重编号稳定ID。新段要讲清入口、事件和后继前提，不把缺失原因留给编剧。
- 恢复：区分“撤销这次删除”“恢复某个节点”和“恢复运行”。只有前两者授权恢复指定节点；从可确认的历史版本取回该对象，以当前图为基线合入，不回滚其他节点的最新正文、连接或媒体。无可靠历史时不能声称已恢复原文；定位不唯一时只确认目标。恢复运行仅继续任务。
- 修改或重连：只修改明确对象与必要接缝。用户的新要求可以改变原主线，这是新的用户编辑，不是Agent内部返工。不得用初次生成的主线锁、结局配额或复杂度缺项否定用户操作，也不删除锁绕过旧验收；当前项目编辑由调用方正常revision事务保存，原规划回执只证明原版本。
- 结构报错：先检查当前图中悬空引用、计数或派生字段；只做不改变现存节点/真实连接的工程清理。若必须新增边、复活节点或删改别处才能解决，报告具体接缝与需要的范围，不从历史完整模板兜底。当前图暂时不满足初次生成形状，不等于用户要求重新生成全图。

## 写入边界

以本轮新读的current复制出proposed，只应用本轮授权差量；先比较新增、删除、恢复、重连的稳定ID清单和用户要求，再交现有项目写入网关执行CAS与读回。当用户要求修正文案、补选择但保留原有复杂度时，按[图形合同](graph-contract.md)将当前实际节点和边映射为plan，使用本版graph_check.inspect与原用户约束复检交叉、分岔和结局；项目JSON合法不等于图形复杂度通过。不能把叙事回汇移到选择卡后仍宣称保留交叉。用户明确删图或要求削减结构则以用户要求为准，只报告影响，不自动补回。没有结构编辑授权时，节点集合、节点类型、真实边和入口必须保持当前值。编剧/媒体写入仅更新目标内容或媒体字段。

写后回读当前全图确认删除未复活、新增未丢失、恢复只涉及目标、其余剧本和媒体未回退。内容承接由作者检查，机器只验证身份、范围、图形和工程合同。
