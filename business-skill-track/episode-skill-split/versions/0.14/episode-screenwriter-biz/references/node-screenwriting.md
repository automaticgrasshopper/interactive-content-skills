# 单节点冷读

## 当前任务

只读取单集写作材料、正式剧本和本文件，判断剧本能否交付。冷读不参与写作，不提供预期答案，也不在正文里补证明。

## 通过条件

1. **路线与边界**：事件、人物、资产、分支准备和结尾忠实于写作材料，没有提前演出后续独占事件。
2. **戏剧节奏**：每个段落或交流段都带来新信息、新阻力、新行动、新关系变化或新结果；同一判断成立后没有继续解释、确认或举证。
3. **人物行动因果**：外部压力和人物理解共同导致关键行动；删去人物在意之事或关系状态，行动不会仍然原样发生。人物或关系变化已经成为可观察的选择、拒绝、隐瞒、让渡、保护、风险承担或对待方式变化，并留下真实的后续行为条件。事实过桥节点没有擅自制造人物创伤或关系转折。
4. **首次理解**：首次出现的人物是谁、与眼前事情的关系、为何此刻需要他，普通观众能够自然理解。入口集只凭正文便能跟上第一轮真正改变局面的行动，不需要额外介绍段或证明对白。
5. **场面与空间**：正文可见可听；剧情需要的位置、进出和物件归属前后不矛盾；没有无效走位或人为摆出的终场队形。
6. **对白**：说话对象和回应关系清楚，语言像当前关系中的人话，没有作者结论、资料搬运、内部分析词或连续字幕骨架。普通场面没有被真人语料参照强行扩成对抗；举证场面只在对方真实抵挡后升级已有证据。
7. **分支与结束**：分支节点的每个冻结动作已经可执行且受同一现场压力约束；正文停在规定位置。

检查只能引用正文自然存在的最小证据，不能要求正文为验收增加一句解释或一个动作。任一项失败，指出现有段落中的问题，废弃整稿并从同一入口重新完整复写；不得贴补成品、修改路线事实或影响其他节点。
