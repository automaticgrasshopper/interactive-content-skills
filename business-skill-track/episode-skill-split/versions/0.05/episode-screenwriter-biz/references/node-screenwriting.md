# 单节点编剧方法

1. 只读取当前节点路线材料、直接前情正文结尾、直接后续入口条件、允许资产和角色公开信息。不要读取全图规划理由或改写路线事实。
2. 把梗概还原为连续事件链：发现或入口、人物首次行动、阻力反馈、人物调整、局面转折、状态变化和停止位置。每一步必须由前一步触发，不用字段名或抽象过程句代替事件。
3. 在`场景和段落展开计划`中先列场景展开表。每场只写五项：`场景目的`、`人物行动`、`阻力反馈`、`局面转折`、`出口状态`。同一时间地点且没有新转折时不强拆场；每场必须改变信息、关系、风险或行动条件之一。
4. 按展开表写行动底稿，固定事件顺序、场景、角色、道具、入口状态、动作结果和停止边界。先让人物做事并收到反馈，再决定哪里必须开口；底稿不是摘要，也不是正式正文。不用目标字数、动作段数或台词比例衡量完整度，只看必要的行动、阻力、调整、结果是否实际发生。
5. 扩写成清楚、可拍、能顺读的正式剧本。允许补不改变因果的场内动作、停顿和反应；不得新增角色、场景、道具、规则、证据来源、选择、结局或未来情节。
6. 使用`【地点·时间·内/外】`场次标题和`人物：台词`。动作必须形成接触、阻力、反馈和结果，不写镜号、景别、运镜、作者判断或抽象心理。
7. 把对白功能检查与降载人话复检分开执行：先在完整场面中判断每句是否产生回答、拒绝、行动或策略变化；再卸掉拓扑、后续任务、篇幅期待和作者意图，只凭相邻话茬、人物关系、当下目的与下一动作逐句删除或直说。删除只复述画面或设定的台词、同义追问、重复确认和没有引发新行动的往返；保留现实关系和话轮真正需要的称谓、承接与态度。删减后若场面缺环，补真实动作、阻力、反应或结果，不补台词长度。
8. 当前节点只拥有路线梗概要求已发生的变化。后续梗概把动作作为核心冲突、核验、选择或结果时，该动作由后续独占；当前正文停在`stop_boundary`。
9. 正文后完成连续性与冷读：核对前情能否进入、路线事件是否逐场发生、状态变化是否落地、下一入口是否成立、对白是否可说且不可再删、资产是否实际出现、是否越界。

失败时只重写当前节点的最早失效环节；不得修拓扑或其他节点。
