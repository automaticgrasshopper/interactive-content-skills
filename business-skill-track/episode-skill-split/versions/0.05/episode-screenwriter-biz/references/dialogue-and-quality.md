# 对白、表演与质量验收

- 以当前节点自然戏剧体量为准，不设正文长度、动作段数、台词数量或台词占比。戏剧点少的节点允许短，只要入口、行动、阻力、变化和停止边界完整成立；不得为了显得完整增加闲聊、假争论、重复解释或装饰性动作。
- 台词必须像人物在当前关系和场合会说的话；普通搭话、确认、迟疑、追问、拒绝和反应占多数，承重句只放关键处。
- 每句台词至少承担一项现场功能：推动行动、形成阻力、改变策略或完成必要铺垫。画面和上一句话已经表达清楚的信息不要再说一遍。
- 功能信息用现代汉语直说清来源、规则、代价和当前行动；悬念可以保留真相，不能让观众不知道发生了什么。
- 命令、请求、质疑和风险判断改变他人行动时，让对方真实接住、顶回、迟疑或确认。连续四个最短语义骨架属于字幕式对白，危急口令、无线电协作和程序确认除外。
- 不用工整金句、破折号机锋、作者腔、抽象声线、直接心理、重复模型动作或人物卡登记句。
- 文字证据推动剧情时，保留画面并让关键信息自然进入可听对白；随后接人物反应、判断或行动。
- 首次出场通过现场动作、权限、自然称呼和关系反应说明身份、关系及此刻相关性；不要让熟人互相背人物卡。
- 对峙必须至少两人开口并发生权力或筹码变化；高潮和关系转折中的核心人物要有真实话轮。
- `关联角色/场景/道具`只列正文实际出现的正式名称，且正文出现与列表双向一致。

## 对白功能检查与降载人话复检

完整剧本写完后，把对白功能与语言自然度分开检查；同一次判断不得一边证明台词“有戏”，一边判断现实中的人物会不会这样说。

### 第一步：对白功能检查

仍读取完整场面，逐句判断它是否让对方回答、拒绝、回避、执行、停止或改变策略。连续发布设定、一问一答搬运资料、角色互换后仍成立、人物自述动机主题、只复述画面或不产生现场反应的台词，登记为待删或待改；不要用普通话茬把无效台词扩成更长来回。

### 第二步：降载人话复检

按场单独提取`人物：台词`，锁定事实、因果、选择、结尾和已经成立的动作结果。此时暂时不读取拓扑、情绪功能、后续反转、篇幅期待和作者意图，只保留：前一句台词或紧邻动作、双方身份和关系、说话人此刻希望对方立即回答或执行的一件事、下一步必须发生的可见行动。

依次处理：

1. 能删除且不影响理解、行动、阻力、策略或后续入口，直接删除。
2. 能用普通请求、回答、拒绝、追问或改口直说，就用当前人物最顺口的直说，不换成另一句更精致的句子。
3. 一句话同时承担施压、总结、人物塑造、伏笔和转场等多个任务，只保留当下交流必需的一项，其余交给已经允许的动作、后续来回或删除。
4. 人物说出作者判断、场面总结、条件格言、海报句或“聪明话”时判失败，即使它兼有戏剧功能。
5. 复检者不能用一句更朴素的话说明这句具体要对方回答或做什么时，判失败。

普通关系中连续四个话轮都只剩最短信息骨架时，检查是否误删了有作用的称谓、代词、状态承接、态度或关系指向；危急口令、无线电协作和程序确认可以短促。只保留现实关系和话轮真正需要的口语成分，不机械补语气词。复检后确认问题、命令、请求和指责仍得到回答、拒绝或可识别的回避。

对白删除或直说后如果暴露因果跳步、阻力不足或结果没有演出，返回行动底稿补真实动作、反应、调整或结果。不得因为正文变短重新添加台词，也不得发明冻结材料之外的设备、按钮、灯号、流程、审核字段或证据细节来制造场面。

冷读必须额外做一次删冗检查：逐段询问“删掉这句是否影响行动、阻力、策略或后续入口”；不影响就删除。冷读问题必须具体指出当前正文中的事实、动作、对白或接缝，并说明是否已修复；`验收结论`只能在所有质量检查通过后写`PASS`。`quality_checks`至少覆盖`route_fidelity`、`stop_boundary`、`continuity`、`dialogue`和`asset_consistency`，每项证据必须可在正文逐字找到，不能写“已检查”“符合要求”或重复梗概。
