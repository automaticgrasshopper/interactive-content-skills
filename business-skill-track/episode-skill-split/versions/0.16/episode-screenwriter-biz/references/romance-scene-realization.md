# 恋爱关系场面实现

只在企划、人物关系或当前路线明确包含恋爱主线或恋爱体验时使用。恋爱是事业、调查、冒险等主线的辅助体验时，不另起撒糖事件；让同一个任务动作同时推进现实目标并显出两个人为何只能以这种方式共同完成。

甜感优先来自三个连续事实：一方对另一方作出并非对谁都会有的区别对待；这种对待准确回应对方当下真正需要的帮助、空间、尊重或兜底；对方识别后以接受、调整、回护或承担作出回应。只有接触、注视、脸红、照顾或知道秘密，不足以证明双方关系升级。

当前节点没有冻结关系进展时，可以在既有关系范围内通过默契、尊重、优先顺序、小额承担和双方回应维持甜感，但不得替单方面好感盖章，不得制造告白、占有、嫉妒或承诺。这样的表达只属于当前场景；只有它使下一次相似处境中的对待方式真正不同，才登记为关系变化。值得以后自然回扣但尚未改变行为基线的内容，可以登记为共同记忆。

选择点用具体行动承载关系含义，例如公开支持还是保持距离、说出风险还是独自隐瞒、让对方共同承担还是把他排除在外。不得把选项改写成抽象的“相信/不相信”“爱/不爱”。

人物说话和行动都先服务眼前任务。甜感从区别对待和双方回应中自然产生，不用旁白、心理解释或泛用甜言总结。
