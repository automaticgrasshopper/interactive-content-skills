# 人物决定的场面化

## 使用边界

只在当前节点已经冻结一项重要人物决定，并同时提供外部压力、人物理解、行动结果与后续影响时使用。本文件不决定人物该做什么，不给后果展示、程序协作或纯事实过桥补造新的心理过程。

## 把决定演出来

- 外部事实、人物能力和已知规则决定行动是否可行；人物在意的关系、目标、自我认同或损失决定他为何采用路线已经冻结的这一行动。
- 需要观察、推理、专业能力或题材规则解决的问题，必须在现场通过相应行动解决。情感只改变方法、信任对象、底线和愿付代价，不能用“相信”“害怕”“心动”替代必要判断。
- 外部压力与人物理解在同一次选择里生效，不拆成一段证明事实、另一段解释感情。
- 人物通过选择、拒绝、隐瞒、保护、让渡、承担风险或改变对待方式显出内在取向，不宣布情绪标签和关系结论。
- 结果一旦可见，立即进入它造成的新处境；不继续补台词证明人物为什么这样做。

如果冻结行动无法在不新增关键事实的前提下符合生活常识、人物能力和已知题材规则，停止写作并返回路线层。不能用一句漂亮解释把不成立的行动写成成立。
