# 中文台词质感指南(去翻译腔 + 去 AI 味)

> 写 plot 的对白时读本文。目标只有一个:让台词像**中国人真在说的话**,不是英译中,不是 AI 腔。
>
> 署名:本文"禁用词与句式底盘"部分改编自 [oh-story-claudecode](https://github.com/worldwonderer/oh-story-claudecode) 的 `story-deslop`(MIT License);"语体分桶"的语感取样自公开素人短剧语料([iEdric/chinese-shortscript](https://github.com/iEdric/chinese-shortscript)),仅提炼句式规律、不整段搬运。

## 0. 为什么这份东西存在

本生成框架很难靠复杂调度与画面扛戏,**台词是戏剧和信息的唯一可靠主载体**。台词一旦"不像人话",实机看起来就空、就假。而中文和英文的发力方式根本不同:

- **英文**:喜欢用聪明的构造把话"说破"--先抛主句,再用破折号/同位语补一个机锋(setup → punchline)。
- **中文**:把刺**藏在一句平白的主谓宾底下**,字面越直白、底下越有话。中国人爱看的是"看似直接、其实不直接"。

所以照搬英文的抖机灵结构,就是翻译腔的根。下面分三层治:反翻译腔内核(通用)→ 禁用词底盘(通用)→ 语体分桶(分题材)。

## 1. 反翻译腔内核(通用,最高优先级)

**1 定语前置,禁英式后置补语。**
中文修饰语在名词前。禁止"主句 + 破折号 + 补一个比喻/同位语"的英式揭示结构。
- ✗(翻译腔):"这酒我喝着像掺了水--就像贵公司的报表。"
- ✓(中文):"沈家的酒,从来不掺水。掺没掺,喝的人心里有数。"("掺水"字面是酒、底下是账,潜台词在平白话底下)

**2 潜台词优于机锋。**
狠话用平白的短句说,把攻击藏在字面之下,不自造聪明比喻。
- ✓ 表面客气、底下宣主权:"露露是我老婆,不仅仅是你的同学了,你别让她参加你们的什么聚会了。"(没有一个狠字,"不仅仅是"就是刀)
- ✓ 冷刀:"我以为这不是忽然,而是必然。"

**3 反问句承载攻击。**
中式吵架大量用反问,比陈述更有压迫。
- ✓ "有这样怀疑自己老婆的吗?有这样怀疑自己女儿的吗?"
- ✓ "你给我装什么糊涂?"

**4 俗语/歇后语当武器,不自造英式比喻。**
- ✓ "只怕是黄鼠狼给小鸡子拜年,没安好心。"
- ✓ "两条腿的蛤蟆不好找,两条腿的女人还不有的是。"

**5 主谓宾直出 + 短句,狠话不加从句。**
- ✓ "我不接。" / "你少装了你。" / "废话少说,我的那一半呢。"

**6 留白与迂回。**
中文常"不把话说满":半句、答非所问、"你自己想""我什么都没说"。
- ✓ 子杰问西西像谁,露露岔开:"她说像文宾,说了好几次了,你说扯不扯?"

**7 口语要带冗余与互动,别写成书面简洁(最容易犯,模型默认爱"高效")。**
真人说话是冗余的、对着人说的、大白话的;书面中文才压缩。生成时别把话写"干净"了--一简洁就露书面相、就出戏。
- **加口语垫词**(功能性话头,无信息量但有说话肌理):我告诉你 / 你听我说 / 说白了 / 不是我说你 / 你自己看 / 你自己清楚 / 我把话撂这儿。
- **直接对着听者说**(交互性):反问、挑战、招呼--"不信你自己看""你说呢""你还转得动吗"。
- **指示确认**:'这就是那份''就这么个事',别用'这份/此事'这种书面简写。
- **意思落地**:别用'到头了''也就那样'这种模糊省略,说清楚到底怎么样。
- **狠话用大白话 + 潜台词,别为了漂亮用构造比喻**('空桌子''掺水的报表'这类文人意象);潜台词不靠漂亮意象,靠平白话底下的意思。
- ✗(书面压缩):"三年前这份鉴定,编号在这儿。做检查的医生,我也见过了。"
- ✓(口语):"这就是三年前的那份鉴定,不信你自己看编号,我告诉你,做检查的医生我也去见过了。"
- ✗"顾家一撤,你手里就是一张空桌子。" → ✓"顾家的钱一抽走,你这盘子还转得动吗?你自己清楚。"
- ✗"那顾家的钱,也就到头了。" → ✓"那顾家的钱,你一分都别想。"
- **垫词要"扛态度",别写成可删的废字**:让口语垫词跟语气 / 权力 / 人物绑死("行啊,翅膀硬了"删了就丢了崇山的讥诮;"你自己清楚"删了就丢了逼视)。下游故事版贴帧切镜时会压时长、删"多余"字,垫词只有扛着态度才不会被当废字削平、把口语味抹回书面。

> 两个别搞混：① **短句 ≠ 电报体**——短是对的，但要保留口语的连接、垫词、对听者的招呼，别把连接词也砍了。② **口语垫词（我告诉你/你自己看）≠ 第 2 节 story-deslop 要删的文学冗余（“缓缓”“一丝”“白色的”）**——前者是功能性说话标记，保留；后者是修饰灌水，删。

**⑧ 信息分层：功能信息必须一遍听懂，禁把规则压成对联谜语（治“台词听不懂”的根，凌驾一切修辞）。**
台词按信息性质分两层，它们的写法不一样：
- **功能信息**（世界规则 / 金手指怎么用与代价 / 谁对谁做了什么 / 因果）：观众**必须一遍听懂**。绝不许压成对仗、文言判断句、四字诀、咒语——把最该说清的规则压成谜（“镜照真，人偿岁”“照一次赔一次”）是重大失败。金手指规则可以有神秘感，但用法与代价必须用大白话讲透（✗“镜照真，人偿岁” → ✓“这镜子能照出眼睛看不见的真东西，可照一回，人就少活一截”）。
- **氛围 / 悬念信息**（神秘存在的话、故意留的伏笔）：**可以留谜**，但同场必须有在场的人当场替观众接住——追问它、怔一句“你给我说人话”、或事后翻译一遍；不许留一句谜就过、让观众自己猜（✓神秘声音说“沙一满，路就变”，主角立刻怔“什么沙满路变，你说人话”）。

## 2. 禁用词与句式底盘(通用,改编自 story-deslop)

写台词与舞台指示时,命中即改。

**最毒句式(出现即修):**
- ✗ "不是 A,而是 B" / "不是 A,不是 B,而是 C"(最毒 AI 句式)→ 直接写 B。
- ✗ ",带着......"万能状语("他笑了一下,带着一丝嘲讽")→ 拆短句或换动作。
- ✗ 无情绪声线:"声音不大,却带着......""语气毫无波澜""平静无波"→ 直接写台词内容或动作。
- ✗ "他/她知道......""他/她意识到......""他/她终于明白......"→ 用行为展示,别直接告知。

**标点铁律:正文(叙述 + 对白)禁用破折号 `--`/`-`、双连字符 `--` 和省略号停顿。** 改用句号、逗号、短句或动作断句。(这条正是"破折号 zinger 是英式"的技术落地)

**一级禁用词(出现即替换):** 仿佛、犹如、宛若、一丝、一抹、些许、几分、缓缓、微微、轻轻、淡淡、不禁、深吸一口气、眼中闪过、嘴角勾起、眉头微皱、瞳孔一缩、指节泛白、心中一动、心头一震、不由得、不容置疑、显而易见、闪烁着光芒、深邃、凛冽、话锋一转。

**替换策略:抽象→具体,告诉→展示。**
- 抽象情绪 → 具体动作:"紧张"→"手在抖"
- "感到 XX" → 外化:"感到愤怒"→"攥紧拳头"
- 书面 → 口语:"不容置疑"→"就是";"瓦解"→"散了/没了"
- 解释性描写 → 留白:"他因为害怕而后退"→"他退后一步"

**替换不复用:** 同一问题多处命中要给不同写法;每次都"垂下眼"、每个动作都"了一下",替换产物本身就成了新的 AI 指纹。

## 3. 语体分桶(分题材,dialogue_intent 对应)

不同题材/场合,人说话的方式不同。按本集 dialogue_intent 与题材取对应桶。

### 桶 A |都市摊牌 / 猜疑(dialogue_intent=对抗,最贴豪门爱情)
- 表面客气底下宣主权:"我这怎么也是个家,你别让她参加你们的聚会了。"
- 短促攻防:"你不用给我转话题。""你不用狡辩。""莫名其妙!"
- 熟人软钉子:"客气就变成外气了。"
- 冷刀+俗语:"黄鼠狼给小鸡子拜年,没安好心。"

### 桶 B |暧昧 / 傲娇 / 口是心非(dialogue_intent=关系,乙游核心)
- 斗嘴顶话:"我娶定你了!""不怎么着!我甩定你了!"
- 抠字眼挡回去:"未婚夫而已啊!又不是婚夫,还有一个未字呢!"
- 口是心非(说反话):抱着对方说"我讨厌你......";心动了说"霸道!可恶!"
- 傲娇代替示好:"本来我还在犹豫要不要答应这桩婚事,现在我决定了,我要结婚!谢谢你啊。"(对情敌说,用赌气宣示)
- 市井长辈的糙智慧:"放长线钓大鱼,舍不得孩子套不着狼!出去一个,回来两个!"

### 桶 C |对峙 / 威胁 / 审问(dialogue_intent=对抗,涉案/权谋)
- 血性直给、不铺陈:"你当我傻啊?""你他妈怎么那么罗嗦?"
- 价值观一句砸下:"人为财死,这点儿伤又算得了什么。"
- 逼问节奏:短句连击,一轮不成再一轮,狠话最后落。

### 桶 D |古装 / 宫廷礼制(跨题材复用,注意身份语体)
- 身份称谓定尊卑:"放肆,这是我们牛庄主!""小人不知。""属下不敢。""喳。"
- 上位者的压:"朕的话也不听吗?""你老实交待。"
- 威胁用具体后果,不用抽象狠话:"下次再知道你养狗伤人,就剥你皮,炖你的肉。"

## 3.5 交锋写法:对峙 / 宣战场,"宣告 + 众人沉默" 是废场

对峙、宣战、摊牌是全剧最该密的场。最常见的失败是写成"一个人华丽宣告 + 众人震惊沉默 + 情感主人掐掌心"--又稀疏又假,因为没人真在对话,主角在冲突最高处失语。对峙场必须是**交锋**:多方各有原句、权力多轮易手。

**✗ 废场(一人宣告 + 沉默反应):**
> 疏影走到主桌前:"我回来拿回属于我的东西。不多,一个姓,一个家。"满场骤静。崇山:"小满,带疏影......小姐,去客房。"小满笑着应下,指尖掐进掌心。

问题:疏影一句海报标语(工整两项列表,不像人张嘴);情感主人小满 0 句、只掐掌心失语;崇山靠省略号自我修正抖包袱,在屏幕上像口误;全场没人真对话。

**✓ 交锋(三方各有原句、权力两次易手、无人失语):**
> 疏影看着小满手里的空杯:"沈家的酒,你倒是喝得惯。"
> 小满笑不变:"客随主便。姐姐想喝哪杯,我给您满上。"
> 疏影不接"客"字:"客?这楼里我住了十八年的时候,你还不知道在哪儿。"
> 崇山起身,对小满亲昵、对疏影生分:"小满,累了先坐。沈小姐远道回来,收拾间客房。"

好在哪:疏影"你喝得惯"点她不配 → 小满"客随主便"反手把疏影框成客 → 疏影"我住了十八年"夺回 → 崇山用"小满先坐"的亲昵对"沈小姐"的生分**自然钉座次**(不靠结巴)。四拍有词、权力两次易手;情感主人没失语;登场是说话不是念标语。

## 4. 生成期自查(写完 plot 过一遍)

- 每句台词是否像"这个人在这个场合真会说的话"?读出来别扭就是假。
- 台词读出来像"书面简洁"还是"真人张嘴"?有没有口语垫词 / 直接对听者 / 指示确认?意思有没有落地(无"到头了"式模糊)?狠话是大白话+潜台词还是构造比喻(空桌子/掺水报表)?
- 有没有破折号 zinger、英式后置补语、"不是 A 而是 B"、"眼中闪过一丝"这类翻译腔/AI 腔?
- 狠话是不是藏在平白短句底下(潜台词),还是靠聪明比喻说破(英式)?
- 攻防是不是绕、垫、才落,还是一句话捅到底(太快)?
- 语体是否匹配题材与身份(豪门 ≠ 古装 ≠ 涉案)?
- "说了句俏皮话"这种概述有没有?必须写出那句话本身。
- 一遍过自检(信息分层):把每句**功能性台词**(报信息/讲规则/交代因果)单拎出来,假设观众没上下文、只听这一遍——能不能抓到信息点?抓不到=压过头了,拆成大白话重写。世界规则/金手指代价是否被压成对联谜语(“镜照真，人偿岁”式)?谜语是否只在神秘方嘴里、且同场有人替观众翻译?
