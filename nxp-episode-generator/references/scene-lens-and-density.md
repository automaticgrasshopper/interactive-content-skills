# 单点情节题材透镜 + 每场戏体量（治"有质感但平、每场戏太少不精彩"）

> 写每一集 plot、排每一场戏之前读本文。目标只有一个：**让每个情节点都"过了题材透镜"、每场戏都有足够的戏**——不是氛围满分、戏剧动力为零的文艺慢热开场。
>
> 与上游《结构判据》《校验判据》同源（"买包子发现包子坏了"案例）。上游只在大纲层用它定情绪脊；**真正在写情节点的是本模块，所以透镜必须在本模块逐场落地。**

---

## 一、为什么"有质感却不精彩"——平情节陷阱

模型很容易写出"标准到平庸"的戏：**一件真实的事 + 普通人的正常反应 + 常识性收口**。例如：

- 穿越醒来 → 摸脉数心跳 → "缺水"（生理正常反应）
- 照镜子 → "换个壳子，接着活"（立人设，常识收口）
- 递药 → 闻一闻 → 皱眉（正常警惕，然后切场）

这些**画面有质感、台词不翻译腔**，但它们都是**平情节**：题材（医/悬疑/修仙…）根本没有下沉到这个情节点里去。换个题材，这几场戏几乎原样成立——**这就是"感觉没出来"的病根**。

**平情节只能当铺陈，禁止作为一场戏 / 一集的落点。**

---

## 二、题材透镜四步（每个关键情节点必过）

把一个情节点，按下面四步"过一遍透镜"，让它从平情节变成只有本题材才成立的精彩戏：

```
①落地一件具体的事      —— 写实、可信、贴自然逻辑（例：递来一碗药）
②过题材透镜换「反差物」  —— 换成一个"题材独有、换个题材就不成立"的东西
③题材逻辑内收口升级     —— 收口不是常识解决，而是在题材规则里把事态推高一级
④留双义钩子            —— 结尾留一个"帮 or 害难辨"的口子，成为下一段催化剂
```

**核心是第②③步：反差物 + 题材逻辑收口。**

### 反差物示例（同一件事，过不同题材透镜）

| 落地的事 | 平情节收口（✗禁作落点） | 过透镜后（✓） |
|---|---|---|
| 包子坏了 | 老板补钱、我没吃 | 恐怖＝馅里疑似人肉、见指甲；修仙＝馅里一颗金丹；修仙奇幻＝金丹点石成金 |
| 递来一碗药 | 闻着不对、皱眉不喝（现代人正常警惕） | **医题材**＝她一尝就报出这是什么药、下错了君臣佐使、这剂量三日内必伤肝——用"医"的专业独占反差物，当场识破，且这识破**只有她这个现代医生能做到** |
| 穿越醒来 | 摸脉、数心跳、看镜子认脸 | **医题材**＝她下意识用现代急救手法处理身边一个正在出事的病人（婆母咳血/孩子抽搐），手法与这个时代格格不入，被人当场撞见——金手指第一次亮相就制造"观众已知她是医生、旁人只当她疯了"的反讽 |

> 注意：上游《反俗套》明令，**穿越苏醒→摸脸认镜→自述身份**这类是训练集最高频的第一直觉开场，默认应弃。第一集就要让**金手指（这里是"医"）在一个具体事件里第一次发挥作用**，而不是先花一整集铺氛围。

### 质检三问（每个关键情节点自问）

1. **反差物题材独有吗？** —— 换个题材它还成立，就不算过透镜，是平情节。
2. **收口在题材逻辑内升级吗？** —— 是不是"老板补钱"式常识收口？必须在题材规则里把事推高。
3. **钩子留了口子吗？** —— 最好是双义钩子（帮害难辨），成为下一场的催化剂。

三问但凡有"否"，这个情节点就还是平的，重写。

## 三、每场戏的体量（治"每场戏太少、不精彩"）

现在常见的毛病：一场戏＝**一句△动作 + 一两句短台词就切下一场**，节奏碎、单薄，token 被压缩。根因往往是**情节点是平的、本来就没肉可写**——先过透镜，戏自然有肉；再按下面撑够体量。

**每一场戏（【场N】）的硬要求：**

- **一场戏必须完成一次"可指认的转折"**：攻防互换 / 信息落差揭开 / 关系或权力升降。只写"一个动作 + 一句台词"没有转折的，不是一场戏，是一个镜头，合并或写足。
- **关键戏必须展开成多轮交锋**：不许"一人递东西 + 一人一句反应"就切。要写出谁逼、谁挡、几轮往返、谁先露破绽——让台词把戏顶起来。
- **反差物要"当场用足"**：透镜换来的反差物（那碗有问题的药、那具用现代手法救的病人）必须在这场戏里被**具体地、专业地、一句句地用出来**，不是点到即止。这是本题材最好看的地方，恰恰最该展开、最不该压缩。
- **禁"氛围代替戏"**：环境/心理/质感描写再好，也不能替代"事态被推进了一级"。一场戏读完，处境必须和开场不一样。

### ✗ → ✓ 对照

**✗ 平、少、碎（现在的样子）：**
```
【场2 · 苏家土坯房 · 日 · 内】
△ 苏承端一碗药进来，脸色沉。
苏承：喝了。
△ 林晚没接，凑近闻了闻，皱眉。
（切场）
```
戏核＝零：她只是"警惕"，题材（医）没下沉，没有转折，两句就切。

**✓ 过透镜 + 有肉：**
```
【场2 · 苏家土坯房 · 日 · 内】
△ 苏承端一碗黑褐药汁进来，撂在炕沿，热气冲脸。
苏承：趁热喝，郎中开的。
△ 林晚没接。她低头一嗅，指尖蘸了一点抵在舌尖，眉头先松后紧。
林晚：附子、干姜……还有半夏。（抬眼）谁开的？
苏承：镇上回春堂的钱郎中。怎么？
林晚：附子反半夏，十八反头一条。这两味一块儿下，是拿命试。（把碗推远）你婆母上个月是不是也喝的他的方子？
△ 苏承脸色变了，端碗的手一沉。
苏承：……你怎么知道？你不是不识字。
林晚（极轻）：我不识字，可我认得死人是怎么死的。
△ 门外那两个嚼舌根的声音停了。
（钩子：钱郎中的方子究竟是庸医，还是有人借他的手——上一个喝药的人已经死了）
```
反差物＝"十八反·附子反半夏"（只有懂医的人能当场识破，换个题材不成立）；收口在医的逻辑里升级（婆母的死有了新解）；双义钩子（庸医 or 借刀杀人）；多轮交锋（递—拒—报药名—追问—反将—失口）。**戏一下子就立起来了，字数是撑出来的，不是灌的。**

## 四、落到本模块的硬规则（正文已写死，这里给全）

1. **每集至少一个关键情节点必须过题材透镜**（四步齐、质检三问全过）；平情节只能当铺陈，禁作一集的落点。
2. **第一集必须让金手指在一个具体事件里第一次发挥作用**，禁纯氛围铺垫开场、禁训练集均值级穿越苏醒套路（摸脸/照镜/自述身份）。
3. **每场戏必须有一次可指认的转折**；关键戏展开成多轮交锋；反差物当场用足、不点到即止。
4. **禁用氛围/质感代替戏剧推进**；一场戏读完处境必须变化。
5. plot 字数下限照旧（≥350，≤2集放宽≥250），但**字数要靠"过透镜后的戏"自然撑出来，不是靠拉长描写或灌水**。
