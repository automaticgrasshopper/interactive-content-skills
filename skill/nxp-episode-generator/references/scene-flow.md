# 场景流畅度：制片格式只是"皮"，内核是流畅的文学脚本

> 写 plot 前必读。本文治的是本模块**这一版最严重的回退**：自从 plot 改成"制片级剧本格式"（△动作 / 人称 / 台词分离）后，模型把格式当成了写作方式，对着空格子填表，把本来连贯流动的一场戏切成互不相干的碎块，流畅度大幅倒退。

---

## 0. 一句话认知（最重要）

**制片级格式 = 一层给外行看的排版皮，不是写作内核。**

- 为什么要这层皮：`△动作提示 + 人称 + 台词` 这套排版，暴露给**外行**（制片、投资方、非专业读者）时，会让他们觉得"专业、像那么回事、可直接开拍"。行内导演本来就读得懂文学脚本、也需要留白空间，这层皮是给外行的"信任感"。
- 皮底下是什么：**还是那部流畅的文学脚本**——我们自己写脚本一向偏文学脚本（动作—台词—反应因果连淌、一气呵成），只是这次换成了"动作提示+人称+台词"的形式来排。
- **所以：内核的流畅度必须和我们之前写的文学脚本一模一样，一个字都不许因为"换了格式"而回退。** 换皮 ≠ 换写法。

---

## 1. 正确工序：先写流畅文学脚本，再翻译成制片排版

**✗ 错误工序（这次回退的真凶）：** 直接对着模板
```
△____
角色：____
△____
角色：____
```
一格一格往里填——填一个动作、一句台词就切场。结果：每块都"对"，合起来是散的，因果流断裂，戏又碎又薄。

**✓ 正确工序（两步）：**
1. **先在脑子里把这场戏写成一段流畅的文学脚本**：动作勾出台词、台词逼出反应、反应带出下一个动作，一环扣一环淌下去，像下面《听墓人》那样读着顺。
2. **再把这段文学脚本"翻译"成制片排版**：客观动作归到 `△`、人物开口归到 `角色名：台词`。**翻译只改排版、不改流动**——原来连着的因果链，排版后依然连着。

翻译完自检：把 △ 和台词行**顺着读下来**，是不是还像第 1 步那段文学脚本一样顺？如果读着是"一条动作、一句无关的话、又一条动作"的跳跃感，就是填表填出来的，返工。

---

## 2. 流畅范例：同一场戏，文学脚本 → 制片排版（流动感不变）

### 第 1 步·文学脚本（我们本来就擅长的写法，读着顺）

> 苏承端着一碗黑褐药汁进来，热气冲脸，撂在炕沿："趁热喝，郎中开的。"林晚没接。她低头一嗅，眉头先松后紧，指尖蘸了一点抵在舌尖，抬眼问他："附子、干姜，还有半夏……这方子谁开的？"苏承说是镇上回春堂的钱郎中，反问她怎么了。林晚把碗往外推了推："附子反半夏，十八反头一条。这两味一块儿下肚，是拿命试。"她顿了顿，盯着苏承："你婆母上个月，是不是也喝的他的方子？"苏承端碗的手一沉，脸色变了："……你怎么知道？你不是不识字。"林晚极轻地说："我不识字，可我认得死人是怎么死的。"门外那两个嚼舌根的声音，不知什么时候停了。

因果连淌：递药→她嗅出问题→报药名追问→他答→她点破十八反→再逼问婆母的死→他失口→她收刀。**一气呵成，没有一处是断的。**

### 第 2 步·翻译成制片排版（同一段，只换形式，流动没丢）

```
【场2 · 苏家土坯房 · 日 · 内】
出场：林晚、苏承
△ 苏承端一碗黑褐药汁进来，热气冲脸，撂在炕沿。
苏承：趁热喝，郎中开的。
△ 林晚没接。她低头一嗅，眉头先松后紧，指尖蘸了一点抵在舌尖。
林晚：附子、干姜，还有半夏……（抬眼）这方子谁开的？
苏承：镇上回春堂的钱郎中。怎么？
△ 林晚把碗往外推了推。
林晚：附子反半夏，十八反头一条。这两味一块儿下肚，是拿命试。（盯住他）你婆母上个月，是不是也喝的他的方子？
△ 苏承端碗的手一沉，脸色变了。
苏承：……你怎么知道？你不是不识字。
林晚（极轻）：我不识字，可我认得死人是怎么死的。
△ 门外那两个嚼舌根的声音，不知什么时候停了。
```

对照：每一句台词都勾着上一个动作、逼出下一个反应；△ 承载连贯动作而不是孤立一条。**排版变了，流动一模一样。**

## 3. 反例：填表式碎场（《悬壶记》第一集犯的病）

```
【场2 · 苏家土坯房 · 日 · 内】
出场：林晚、苏承
△ 苏承端一碗药进来，脸色沉。
苏承：喝了。
△ 林晚没接，凑近闻了闻，皱眉。
（切场）
```

病在哪：
- 对着模板填了"一个△+一句台词+一个△"就切场——**填表**。
- 三块之间没有因果流：递药→"喝了"→闻→皱眉，没有一句勾出下一句，戏没往前走。
- 题材（医）没下沉：她只是"警惕"，换成任何题材都成立（见 `scene-lens-and-density.md`）。
- 读下来是跳跃的三个镜头，不是一场淌着的戏。

---

## 4. 场与场之间也要流畅（不只场内）

- **场间要有推力承接**：上一场的钩子/未决问题，要成为下一场开场的推力。禁"场1醒来→硬切场2递药"这种两个独立小品拼贴。
- **信息从戏里自然长出，禁贴片式硬灌**：背景/身世/世界规则，靠当下的动作、台词、冲突带出来。**禁用"路人画外音/村妇嘴替"成段倒背景**（"过了门克死婆母""娶这么个丧门星"这类）——那是贴上去的信息，不是从戏里长出来的，是最典型的不流畅。要交代前情，让在场的人在有动机的对话里带出来。

---

## 5. 写完 plot 过一遍（流畅度自检）

- 把每一场的 △ 行和台词行**顺着读下来**，是不是像一段文学脚本一样顺？还是"动作、无关的话、又一个动作"的跳跃？
- 每句台词是否勾着上一个动作、逼出下一句/下一个动作？因果链有没有断？
- 有没有"一个△+一两句台词就切场"的填表式碎场？
- 场与场之间有没有推力承接，还是硬切拼贴？
- 背景/身世/规则是不是从戏里自然带出的？有没有用路人画外音/嘴替成段硬灌？
- 最终检验：**这一集读起来的流畅度，和我们之前写的文学脚本一样吗？** 只要感觉"回退了、变碎了"，就是把格式当写法填表了，返工。
