# 角色三视图设定表 · 把人物翻译成生图提示词

给写实真人 AI 视频/游戏项目用。核心思路：**版式骨架固定不变，只把人物特征换进占位符**，这样全片每个角色的设定表长得一致、画风一致、同一角色多状态还是同一个人。

完整模板、占位符速查、Sandra 三态范例、三态硬区分表都在 `references/角色三视图模板.md`——动手前读它拿骨架原文。

## 四条铁律（每次生成都要守）

1. **骨架不许改。** 三视图布局（front / side / back）· 右上脸部特写 · 右下静默细节面板 · `no horns` · 末尾整串负向约束（`no text … no Front/Side/Back words`）。这些逐字保留，保证所有角色版式一致。
2. **画风全片一句、所有人物+所有场景共用。** `{ART STYLE / MOOD}` 绝不逐图改，否则会"不是一个世界"。本片基准：`low-saturation muted desaturated palette, naturalistic dim/underexposed lighting, 35mm film grain, gritty grounded bleak British realism`。灰调/颗粒只作用于光线氛围，**别把服装颜色也洗成灰**。
3. **画面里不出任何文字。** 末尾负向串必须带全：no text/labels/captions/annotations/arrows/UI/title/logo/watermark/Front·Side·Back words。
4. **身份要锁。** 纯文生图各自独立生成锁不住脸。要多图/多态是同一个人：选一张当身份基准图，其余用它做图生图/参考图，只改皮肤/眼睛/伤口/服装破损；文字上把"脸部锁"逐字粘到每条提示词的身份句（示例见 references）。

## 工作法

### 第一步：收集人物特征，填占位符
按下面把用户给的人物信息塞进占位符（速查表见 references）：
`{CHARACTER IDENTITY 年龄/性别/人种/体型}`、`{HAIR 发色+长度+发型}`、`{OUTFIT 主体服装}`、`{ART STYLE / MOOD 全片统一，别改}`、`{FACE DETAILS 皮肤/表情/眼神/碎发}`、`{OUTFIT FABRIC}`、`{COLLAR / NECKLINE}`、`{LOWER GARMENT}`、`{ACCESSORIES}`、`{FOOTWEAR}`、`{SIGNATURE DETAIL 角色辨识符}`。

信息不全时，按角色气质补合理默认，并把补的地方告诉用户让他确认。

### 第二步：套骨架，出提示词
把填好的占位符套进 `references` 里的通用模板，输出**一条完整英文提示词**（三段式：身份句 + 外观句 + 版式/负向句）。

### 第三步（按需）：多状态
用户要同一角色的多个状态（如活人/半丧尸/全丧尸），**共用同一框架措辞、同一服装、同一画风**，只改区分锚点——主要压在**眼睛**和**破损程度**上。照 references 的"三态硬区分表"逐态改，身份句保持同一副骨相。

## 输出格式

```
## 角色：<名字> · 状态：<活人/半丧尸/… 或"单态">
<一条完整英文图像提示词——身份句 + 外观句 + 版式与负向句>

## 生成提示
- 身份基准图选哪张、其余怎么用参考图锁脸（如果是多态/多图）。
- 提醒：画风句要和全片其他角色/场景一字不差。
```

## 最容易翻车的地方
- 忘了带末尾负向串 → 图里冒出 Front/Side/Back 字样或标注。
- 逐图改画风 → 角色之间"不是一个世界"。
- 把灰调加到服装颜色上 → 人物失去辨识色。
- 只靠文字想锁脸 → 多图必漂，一定要上参考图/图生图。
