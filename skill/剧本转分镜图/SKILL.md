# 剧本转分镜图 · 让剧本长出很好看的画面

**一句话定位**：给擅长写故事、不擅长做视觉的人用。输入剧本（互动短剧/分场节点），输出一张张**构图讲究、风格统一、人物一致**的分镜静帧图提示词，直接接进视觉小说当背景/场景图。

**融合来源（两套合一）**：
- **骨架**＝剧集级前期规划（层级顺序 / 参考一致性锚点 / 生成风险控制 / 画幅分辨率约束）
- **灵魂**＝导演视觉语法（先诊断戏剧问题 → 挑导演语法 → 固定机位镜头设计）
- **终点**＝一镜两用。分镜就是分镜，一次规划、两种消费：
- **img**：静态帧出图提示词（视觉小说背景图直接用，必给）
- **video**：视频扩展提示词（好的分镜要改视频时用，在 img 基础上加动态）

原则：好的分镜改视频，不好的/暂不做视频的就用静态帧。先能当图，再能扩成视频。

---

## 铁律（先记住这几条，贯穿全程）

1. **静帧思维，不是视频**：产出的是"一张定格画面"。所有"运镜/运动"都翻译成**固定机位的构图**——靠"选哪一刻定格"和"景别+机位+焦段"讲故事，不写镜头运动。
2. **一致性优先**：同一部剧里，人物身份/服装/发型/配饰、场景地理、整体画风与色调，全程锁死不许漂移。**先建"视觉锚点表"，每张图都复用它。**
3. **一场戏先诊断"戏剧问题"**：动手前先答"这个节点要让观众产生什么"（发现真相？压迫？暧昧？悬念？），再挑导演语法，别照剧情平铺。
4. **画幅与分辨率**：视觉小说横屏默认 **16:9、1920×1080**；若做立绘/竖构图另议。风格统一比单张精细更重要。
5. **贴着用户剧本走**：只补"怎么画"，不改剧情。台词/人物/场景以剧本为准，拿不准按字面来。

## 工作流（五步，顺序不能乱）

### 第一步：建立"剧集视觉锚点"（一致性地基，全剧一次）

从剧本抽出并固定下来，之后每张图都引用：

- **人物锚点**：每个出场人物 = 身份 + 年龄段 + 发型 + 服装/配饰 + 面部特征 + 气质基线。（这是人物一致性的命根子。）
- **场景锚点**：每个场景 = 地点 + 空间布局 + 关键道具 + 光源 + 时间/天气 + 材质质感。
- **全剧画风锚点**：美术方向（写实/动漫/水墨/赛博…）+ 主色调 + 光线风格 + 画幅（默认 16:9）。一部剧只定一套，全程复用。
- **相机基调**：给整部剧定一个"镜头质感"（如 35mm 写实、85mm 压缩背景的电影感），让所有分镜像出自同一台相机。

> 若剧本已带"场景与人物总表"（分场剧本节点常有 loc/cast），直接吃它做锚点。缺什么就基于剧情合理补全，并在输出里标注"假设"。

### 第二步：逐场诊断戏剧问题 + 挑导演语法

对每个要出图的节点（一节点≈一场戏），先答一句：**这场要让观众产生什么？** 再按下表挑**一个主导演语法**（最多加一个辅助调味）。详细镜头工具箱读 `references/directors.md`。

| 这场想要的效果 | 首选导演语法 |
|---|---|
| 第一次发现真相 / 奇观 / 亲情唤醒 / 让观众认同 | 斯皮尔伯格 |
| 多线并行 / 倒计时 / 谜题 / 被巨大系统压迫 | 诺兰 |
| 谎言 / 审讯 / 调查 / 被监控 / 压抑控制 | 芬奇 |
| 悬念（观众知危险、角色不知）/ 窥视 / 延迟揭示 | 希区柯克 |
| 群像调度 / 天气即情绪 / 权力移动 / 道德冲突 | 黑泽明 |
| 家庭秩序 / 沉默 / 克制 / 静静旁观 | 小津安二郎 |
| 爱而不得 / 暧昧 / 错过 / 碎片化的亲密 | 王家卫 |
| 欲望 / 复仇 / 精密心理操控 / 对称控制 | 朴赞郁 |
| 仪式感 / 制度恐惧 / 冷峻空间 / 走向疯狂 | 库布里克 |
| 巨大尺度 / 神秘 / 负空间 / 命运压迫 | 维伦纽瓦 |

混搭规则：**一个当骨架（定构图逻辑），一个当调味（只在关键点介入）**，别各画一半。

### 第三步：为这场戏定"关键定格"（选帧，不是分镜运动）

一个节点通常出 **1–3 张图**（视觉小说一个节点常只要 1 张背景/场景图；情绪重、信息多的可到 2–3 张）。为每张图定：

- **定格时刻**：这场戏最该被"拍成一张画"的那一瞬间（发现的脸、对峙的僵持、错身的一刻）。
- **景别 + 焦段**：焦段是性格——
  - 14–24mm 广角：尺度、压迫、负空间、环境吞人
  - 35–50mm 标准：客观、日常、纪实
  - 85mm 中长：人物特写、压缩背景、亲密、把人从环境隔离
  - 135mm+ 长焦：强压缩群像、偷窥/监控距离感
- **机位=态度**：仰拍=让对象变强；俯拍=压小；平视=平等亲近；低位固定=冷静旁观。
- **构图**：对称/三角/框中框/前景遮挡/负空间——直接服务戏剧问题。
- **光线与色调**：复用画风锚点，按情绪微调（冷/暖、光比大小、逆光/顺光）。
- **人物调度**：谁在画面哪、朝向、视线、相对高低（权力/关系全在站位里）。

> 视觉小说适配：背景图**尽量少放或不放主角正脸大特写**（立绘另出），多给"能当场景底图"的中景/环境+人物剪影，方便对话框叠在上面。若该节点需要角色表情，单独标注"立绘图"。

### 第四步：生成风险控制（让 AI 真能出好图）

出图前按这些拆分/简化，避免生成翻车：

- **一张图只讲一件事**：别把多个动作、多处信息塞进一张。信息多就拆成 2 张。
- **人物数量克制**：一张图里命名人物尽量 ≤3；人多用"群像/背影/剪影"处理，别要求每张脸都清晰。
- **避免高难动态**：静帧不写"正在奔跑/穿门/回头的中间态"，改成动作的**开始或结束的稳定定格**。
- **文字不进画**：画面里不要生成招牌/文件上的精确文字（AI 易糊）；关键文字信息交给视觉小说的对话框。
- **一致性复述**：每张图的提示词里都**重新写一遍该人物/场景的锚点**（AI 没记忆，不复述就会漂）。

### 第五步：输出每张图的"出图提示词"

按下面模板，一张图一条。**文生图**用于首次建立场景；**图生图/参考图**用于保持人物或场景一致（把已生成的锚点图当参考）。

## 出图提示词写法要点（决定"好不好看"）

- **提示词结构固定四段**：画风锚点 → 场景锚点 → 人物锚点+当前状态 → 镜头（景别/焦段/机位/构图）+光线，末尾加"16:9，1920×1080，无画面文字"。
- **锚点必复述**：人物长相、服装、场景关键物，每条都完整写一遍，别用"同前"。
- **镜头语言翻成画面词**：不写"推镜/跟拍"，写成定格构图——"人物小、置于画面下方，仰拍巨大对象，逆光剪影"这类**可被一张图实现**的描述。
- **固定机位思维**：默认"固定机位、稳定构图"；靠景别切换和构图讲故事，不写运动。
- **负向约束**：统一加"无画面文字、无水印、无多余人物、无变形手部"等负向词（按出图模型语法）。
- **风格统一 > 单张惊艳**：宁可十张一个调子，不要每张风格跳。所有图共享同一段"画风锚点"原文。

## 出图自检清单（交付前必过）

- ☑ 全剧只有一套"画风锚点"，每张图都原文复用。
- ☑ 每张图提示词都完整复述了涉及人物/场景的锚点（没偷懒写"同前"）。
- ☑ 都是**静帧构图**，没有运动/运镜描述；动作取稳定定格。
- ☑ 景别+焦段+机位+构图齐全，且服务了本场"戏剧问题"。
- ☑ 画面内不含精确文字；关键文字信息留给视觉小说对话框。
- ☑ 一张图信息单一、命名人物≤3；复杂场面已拆图或用群像/剪影处理。
- ☑ 画幅 16:9、目标 1920×1080（视觉小说横屏）；立绘/竖构图另标注。
- ☑ 视觉小说背景图避免主角正脸大特写占满（给对话框留空间）；需要表情走"立绘图"。

## 与视觉小说的衔接（落地口径）

- **一个剧本节点 → 一张背景图**（默认）；该背景对应视觉小说里该 label 的 `@bg`。
- **需要人物情绪 → 额外出"立绘图"**（透明底/半身），对应立绘图层（当前游戏可暂不启用立绘，先只用背景）。
- **出图模型**：优先用支持图片输出的多模态模型（如通过 OpenRouter 调 Google Gemini 图像模型），保证浏览器直连、同一 Key 通道；需要更强人物一致性时再换专门图像模型。
- **命名建议**：`bg_<节点id>.jpg`（背景）、`char_<角色>_<表情>.png`（立绘），与视觉小说资源命名表对齐。
